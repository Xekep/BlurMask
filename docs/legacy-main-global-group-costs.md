# Owned global group geometry for frontend128

`LegacyFreshMainGlobalGroupCosts` pairs the current global D0 final class cache
with actual193860/195520 group geometry. It requires the same owned global case
session and pinned AK/table data. `ReadCosts(span,node,arc)` validates the actual
span's epoch/ordinal through its owner before returning owned class and geometry
snapshots. It does not compute raw NN values as substitutes for final class costs.

Native195520 reads graph90's stored group ranges, graph78/80 primary/secondary
descriptor IDs and ordinary group kind.193860 returns0 for one range. For a group
with multiple ranges, source10 resolves the descriptors' actual line IDs and
source40 retrieves guides. A cross-source assigned group uses the union vertical
interval, as the normalizer does. Chronologically ordered normalization ranges
are not substituted for the stored ranges in this geometry calculation.

The existing exact prefix/suffix separation kernel uses the main sampler's
offset/slope/cap and pinned256-entry table.195520 repeats the resulting integer
over the **19 geometry prototypes** at category-profile20. The35 composite
categories at profile48 map through their GeometryIndex values into those
prototypes. They are different owners/extents. The new adapter uses19 entries.
The older same-source span adapter's35 repeated entries cover the same valid
indices numerically; they are not evidence for the native allocation extent.

The geometry cache keeps private prepared XY, stored-range snapshots and a checked
copy of the table. A caller can recover the old public table's memory, so this
owner verifies the copied float-byte hash before retaining it. Mutating the input
table later cannot change this cache. Returned cost objects also receive copies.

Eight actual raw inputs exercise631 groups, including five cross-source groups,
and631 selected current-D0 class/geometry projections. Python independently
recomputes float32 extrema, guide union, prefix/suffix separations, lookup/rounding
and costs. Three genuine cross-source cases distinguish union height from primary
height. Forty guards cover source/cancellation/bounds and altered table data;
public result/table recovery is exercised directly. Managed/Native captures must
match. Static proof includes22 instructions, two complete PE blocks and an
independent raw category-profile count walk.

This supplies the final class/group-geometry input required by frontend128.
The separate line-aware1941B0 transition cache and cross-descriptor graph status
dispatcher remain necessary before the complete global controller can use it.
No final winner, accuracy or completed multiline text output is claimed.
