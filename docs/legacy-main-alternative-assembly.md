# Main plain alternative comparison and shared TOP collection

`LegacyOwnedMainAlternativeAssembly` restores the post-callback append and
ordinary duplicate-discard stage of `2271F0`. It owns one actual fresh CASE
TOP's result pool. It does not run another terminal search or change the fresh
secondary-alternative limit, which remains one in the checked resource policy.

`LegacyFreshMainPlainResultOwnership.ForkAlternative()` retains the identical
TOP, materialization, source geometry, confidence and274 glyph pool. The new279
publisher has an independent head and node budget, while sharing the TOP's275
span table. Native `1416B0` passes TOP273 to278.V28 at `141773..141782`, then
interns into that span's275 table. Consequently identical span and64-bit glyph
head reuse the same WORD object and WordIndex across forks. Equal labels alone
do not establish this identity. A nested fork retains the original TOP.

`LegacyOwnedMainCompletedAlternative.FromFirstCandidate` consumes an existing
bounded first-candidate completion. `CompleteActualCallbacks` instead requires
the identical actual terminal, complete flush session and chronological
publication tokens. It performs the already transferred quote cleanup and
freshF4 no-op over that publisher's actual WORD list. Allocator400 and two
separate4-byte quote scratch slots remain explicit. Each279 candidate can enter
this completion service once, including failed prefixes.

The assembly appends a constructed40-byte279 row, deriving its cost channels
from that candidate's actual terminal and the first candidate's reference78.
Its WORD and beam identities are typed owners; pointer bytes remain portable
zero placeholders. Reallocation is explicit: the allocator must return complete
storage and preserve the entire previous allocation prefix. Capacity rounds up
by ten as in273.V8/`13BD40`. The portable allocation budget is4090 active rows,
so rounded storage also fits the existing bounded score-normalization service.
An allocation or comparison failure after mutation faults this assembly and
preserves its prefix; it does not roll back or permit a retry.

For each preceding alternative,279.V28/`1421B0` compares flat glyph-reference
streams in native279.Head/Next order. This is not decoded string equality:

- Both current glyph scalars are read before testing the skip branches.
- WORD3C other than-1 makes current FFFC skippable on that side; FFFA is
  independently skippable. The left side has native priority in both tests.
- Exhaustion is checked before skips. An unmatched trailing FFFA is therefore
  unequal to an exhausted stream. Leading or interior FFFA may be skipped.
- Ordinary equality requires the same scalar label, alternate byte and glyph
  byte6 bit40. Other glyph metadata does not enter this predicate.
- WORD boundaries and empty WORD nodes do not themselves separate the streams.
  Initial native WORD heads must be nonnull, so empty initial lists are refused.
- When neither list has active auxiliary WORD60/54 metadata, matching streams
  compare equal. If any WORD has active auxiliary data and another does not,
  they compare unequal. The all-active detailed WORD58-vector branch remains
  explicitly unsupported when reached.

On a duplicate, native `2278E5..227953` destroys the appended279 list and
decrements TOP60 without advancing the accepted alternative ordinal. The
portable release clears only that publisher's Head and rejects later publishing
or forking from the released list. Shared275 WORDs, their indexes and274 glyph
rows remain owned. Historical managed snapshot nodes remain readable; this is
not a model of native allocator addresses or freed memory. Inactive40-byte
storage remains constructed/scored, with a zero portable head pointer.

`FinalizeScores()` applies the transferred273.V60 and final mass-channel
normalization to the active prefix. These numbers are not acceptance confidence.

skip priority, unmatched tails, all glyph kinds, scalar no-write residue,
alternate flags, bit40, WORD segmentation and auxiliary refusal branches.

all2400 constructor, inactive-allocation and final score bytes independently.

inferred alternatives and not a text-accuracy measurement.
