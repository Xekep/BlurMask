# Original-input ordinary patch compatibility

`LegacyLibraryOriginalInputPatchCompatibility.Prepare(actualReplay)` is an
optional owning preflight on the exact adopted publication document, scope,
transferred pending C4D and selected-registry replay. The document retains it as
`OriginalPatchCompatibility`. Once claimed, that replay cannot enter until
preflight has both worked and reported compatibility. If unclaimed, existing
replay/document APIs keep their prior behavior. A preflight cannot be attached
after replay has entered. This is not a CBB receiver or native page acceptance.

The original target is the selected context's **exact parent**, which must be a
constructor-original (no further parent), retain the same CurrentView/document,
and own its INPUT C22. The scope's private creator constructed that original
before its selected copy and before NN/WORD publication. The native constructor
and F8 link are proved by the
[registered original-history contract](legacy-registered-text-patch-history.md).
The original and selected contexts remain distinct owners. The portable preflight
uses the original's immutable data/target identity; it does not invent a native
C4D handle, implement its history log or invoke the global history manager.

The original C20+20 domain is rebuilt from retained raw C49s using the actual
065940 producer: raw ordinal at065B77, target+20 at065BA3, first3/FF03 at
065BAC..BB6, terminal FF05 at065BF1 and C21.VA8 append at065C06. The pinned
0802E0 wrapper skips mode4 and otherwise forwards to07FAF0, which handles native
consecutive-whole-object joins. This fresh raw producer emits3/FF03, not4. Only after
that construction does the factory require exact equality with the original
and selected INPUT C22. Thus an INPUT registration is not silently substituted
for an unproved ink-domain producer. Raw object IDs remain original IDs.

The supported06EC60/077850 branch has a real original target, null optional
mapping/source arguments and actual ordinary operation4/7 commands only. It
copies the original C21 domain, allocates the native raw-presence byte vector,
then walks the retained command prefix. All raw slots in this closed current
view own concrete C49s; the diagnostic vector records that actual ownership.
Operation4 checks each nonempty C22 against C21.V120=081D90. The underlying
unsigned binary search normalizes an FF first fraction to zero but retains the
raw last-endpoint containment comparison. Empty operation4 ranges skip V120;
V120 itself returns false on an empty request. Operation7 does not change
compatibility. Other command kinds, external/prior/cropped raw domains and
other original parents are outside this owner.

Execution success (`Worked`) and the caller output (`CompatibilityByte`) are
separate. For either temporary-domain-copy or raw-presence-allocation refusal,
077850 returns false but still writes its initially true compatibility value.
A successful execution can instead write compatibility0 and stop at an
incompatible command. `CopyOutputBytes` captures those two logical output
channels, not a fabricated native struct. `InspectedCommandCount` is portable
diagnostic prefix metadata. Its incompatible command is included; a canceled
command not yet inspected is excluded.

Preentry cancellation leaves the owner reusable. Entered failure, incompatibility
or cancellation poisons this invocation without rollback; replay and document
DOM application stay blocked. Cancellation is a portable adaptation and leaves
the native compatibility output unwritten (its known caller residue0 retained).
The native allocation-refusal cases write compatibility1. Public methods cannot
provide a success boolean, replacement ranges or flags. Internal named prepared
controls distinguish those failures and an explicit out-of-root counterexample
from actual recognition. Real fresh sources are compatible by construction;
no incompatible prepared range is claimed as inferred metadata.

Lock order is document -> preflight/replay. No reverse owner callbacks occur
while holding child gates. Closing the document or its scope rejects live work;
immutable state/range copies survive with provenance owners retained. The
scope's existing rule against racing downstream work with scope disposal still
applies. This API makes no broad concurrent page/history claim.

The independent probe rebuilds original domains directly from captured raw
point counts and checks actual pending ranges without expected labels. It
separates actual positive inputs, foreign-original refusal, prepared incompatible
ranges, allocation/command cancellation prefixes and closed owners. The numeric
range oracle uses linear unsigned membership, independent of native/runtime
binary search. Existing unclaimed replay/document captures are regression gates.
Static auditing pins the actual domain producer, command dispatch, empty-range
branch, failure/writeback order and original target lineage without running a
vendor DLL. Full CBB/CB7, registered cache versions and native history rollback
remain separate dependencies.
