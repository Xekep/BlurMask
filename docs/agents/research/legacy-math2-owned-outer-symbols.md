# Owned single-source Math2 outer symbols

`Math2Mode0OuterSymbolVector.CreateSingle(actualFirstCopy)` copies one genuine
complete source-aware `Math2Mode0FirstResultCopy` into an independent outer3E
string/range owner. It implements the single-F0 selection of028A80 and the
supported026780 copy. It does not combine independent inferences into a
multi-C23 vector, create CB8 registrations or publish a DOM/formula result.

The [native owner contract](legacy-math2-outer-symbol-ownership.md) pins the
caller,40-byte row fields, default bounded string comparison and multi-source
boundary. One source adds no `<table>` or row-separator markers and strips no
existing markers. Only rows/alternatives/ranges/flags/metadata enter this owner;
decoder score, histories, raw unit IDs and168-byte record identity are not
invented fields in its outer40-byte view.

## Same source, new pool and original ranges

A metadata-only callback in `Math2Mode0FirstResultCopy.OuterView.cs` holds the
same first-copy gate, validates complete/notfailed/notreleased and exposes the
private source rows/ranges only to the trusted copy kernel. Public-style
inspection remains detached. The only change to the existing first-copy file
is its `partial` keyword. Its native frontier write order and old numeric
captures are unchanged.

The new vector retains the exact immutable original `Document`, a new3E library
and its own symbol cells. It does not retain the first-copy object, decoder
Source, Step, model, old pool or event lease. Every nonempty interval is
re-interned in the new pool, preserving byte count and scalar bits separately.
Equal bytes share one identity in that new pool. Source ranges are copied after
the corresponding alternative, preserving original source IDs, fractions and
collection order. This is a C21 copy, rather than a union or whole-stroke
replacement. `ValidateDocument` requires exact original-document identity;
same-shaped foreign documents cannot substitute.

The supported input producer currently has one nonempty alternative per
symbol, flags0, metadataFFFFFFFF and scalar bits0. These are actual fresh input
facts, not thresholds or confidence. The copy preserves these fields and does
not decode, concatenate or rename text. General caller-supplied symbol rows,
multiple alternative vectors and multi-F0 grouping have no production entry.

## Count and failure order

The target creates its independent library, reserves the row vector, initializes
all cells with empty ranges/alternatives, flag0 and metadataFFFFFFFF, then
adopts the full vector count. This matches02687C before source-row filling.
For each row it then writes flags/metadata, reserves one alternative, interns
text, stores byte count/scalar/text, increments alternative count, copies ranges
and completes that row. Prefix inspection distinguishes uninitialized cells,
initialized rows with vector count0, adopted rows, an interned string not yet
stored in its alternative, and a stored alternative whose ranges are not yet
copied. It is a semantic projection; native pointers, padding and allocator
capacity bytes are not fabricated.

Preflight checks source lifetime, shape and a conservative combined16MiB
payload envelope before allocating target payload. Reservation includes the
source-chain bound,24+72 logical library bytes,72 bytes per semantic row plus
its single alternative/reference slots,16 bytes per source range, unique
interval bytes/hex keys and peak temporary string work. This excludes metadata,
CLR headers and detached inspection copies and is not an RSS claim. It can
conservatively reserve upstream payload even after the decoder has been freed.

Before-claim cancellation/budget rejection leaves the input usable. After
claim, fault/cancellation poisons the new target and keeps its diagnostic
prefix; normal reads refuse. Callback disposal of either the source or target
is detected before another payload write. Production convenience creation
releases incomplete targets; friend observers may retain failure state for
inspection and must dispose it. The target pool releases once. Input remains
an unchanged immutable first copy; creating another independent fresh target
is a read-only copy, not a source reset or another NN run. Existing-target
rollback, native temporary marker allocation and generic allocator-failure
order are outside this fresh-target adaptation.

`CopySymbols()` returns detached row/alternative/range arrays. Opaque text
objects belong to the new pool and become unreadable when that target is
disposed. Successful outer payload survives disposal and GC of the decoder
and first-copy owner. Returned value-only range arrays remain inspection data;
they do not authorize publication after target disposal.

## Verification

`LegacyMathOuterSymbols.Probe` takes model.ikrmath, rawMath2.res, the official
ONNX Runtime library and capture.json. It uses actual cold width1, prepared
widths3/16 and a fourth repeated-ink input with one actual shared string pair.
Width3 reverses original input order, preserving the genuine source-ID mapping.
All decoder owners are disposed and collected before outer copying. Separate
positive/negative controls force first-copy GC after outer completion.

There are24 throw/cancel prefixes, targeting the second row for row-specific
stages, and107 guards. Tests cover budgets at limit/limit-1, cancellation,
foreign document identity, detached inspection mutation, repeated destination
copies, incomplete/failed/disposed source, callback source/target disposal,
incomplete and failed normal-read refusals and exact release counts. All target faults leave input
bytes unchanged. No expected transcription labels steer inference.

`audit_output.py capture rawMath2.res firstcopy-capture sourcebound-capture
[same-platform-other]` first runs the tracked raw-AL/C79/C21 first-copy oracle,
then independently derives new-pool aliases, all symbol fields, source ranges,
budget and every initialized-count/alternative/range prefix. It uses tracked
stdlib/NumPy references and can run with `python -I` from outside the repository.
Same-platform Managed/Native captures are compared exactly; no Windows-only
capture hash is imposed on other CPUs/platforms.

`audit_math2_owned_outer_symbols.py report.json` reruns native8-region/69-pin
outer/first-copy/DOM dependency proofs and checks the two new runtime ownership
chains. Vendor libraries are inspected as PE data only. Old first-copy and full
EE4 probes remain independent unchanged regressions.

The next publication still requires a math-specific original field/C23/CB8
owner, source/tag namespace, DAF/freeze metadata and original DOM/Ink edit
receivers. This vector is not accepted text, a final formula or an SDK page.
