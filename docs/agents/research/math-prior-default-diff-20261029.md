# Prior Math cloning, default diff and temporary-writer algorithms

This transfer adds the internal THIRD/candidate/default-diff path and a typed
temporary-writer kernel to the reusable Math library. It does **not** complete
repeat recognition, apply a changed result to the original document, or enable a
new public recognition adapter. The published NovaPen 1.0.0 predates this transfer.

## Ownership and behavior

`Math2Mode0PriorCandidatePreparation` consumes the actual completed NEW neural
result under the existing selected/current-C23/source owner chain. It clones the
selected registry while preserving canonical selection aliases, retains the
shared name domain, clones the old field into a temporary arena, and constructs
the candidate and its pending negative IDs from actual decoder output.

`Math2Mode0PriorDomDiff` takes a private synchronous borrow of that exact cohort.
The default-schema comparator aligns actual old/new children with the native
FLOAT32 edit matrix and tie rules. Produced actions retain their real old writer,
candidate provenance and separate scalar copies. Only those actions enter CB8;
copied diagnostics, tags, arbitrary selections and caller opcodes confer no owning
authority. Claims, ancestor-first gates, revocation and completion fences remain.

`Math2TemporaryWriterKernel` implements the produced operation family 2/4/5/6/7
against typed arena nodes. Deletion selects the **current ordinal**, ignoring the
diagnostic payload identity at +20. Attribute insertion already under the same
parent is a no-op; otherwise it replaces the canonical-name match. Attribute
removal uses exact identity. Scalar copies precede replacement of old values.
The kernel alone grants no current-document or application authority.

The valid scope is the library's default temporary BCC, flag0/no observers, unique
canonical attribute names, and the already proved typed scalar domain. Operations
1/3, arbitrary observer/schema policies and cross-numeric coercion are unported.
Managed arena references, freed markers and prefix observations do not recreate
native memory reuse, raw linked-pointer storage or native A8 transaction rollback.
Budgets cover admitted copy/matrix/action work; they are not total GC/RSS bounds.

## Verification

- The genuine six-case pipeline performs an initial owning application, prior
  selection, zero freeze/current C23, NEW neural evaluation, THIRD/candidate and
  default diff. Each case produces three real INT64 tag edits; CB8 filters all
  three. **Kept0 does not prove application of a changed result.**
- 961 frozen prepared alignments and 1,257 prior/diff controls cover numerical,
  cancellation, fault-prefix, ownership, claim, closure and readiness boundaries.
  Independent NN, candidate and action/range/name audits check actual captures.
- 502 separate frozen typed-arena cases and nine guards cover structural/scalar
  operations. Three tight budgets verify that list scans and shifts are charged
  before the tested mutation. An earlier undercharged implementation is rejected
  by these final controls. Expected fixtures were frozen before compilation.
- Static proof authenticates the actual Engine BCC descriptor `227030`, class
  `2272D8`, runtime `227080` and operation slots, plus 23 functions / 2,153
  instructions against the original PE bytes. The vendor binaries are not run.
- Root compiled 79 authored Math documents and checks their portable PDB against
  the exact repository source bytes. Both probes are exercised managed and as
  Windows Native AOT. CI adds the same managed/native checks on its Formula ABI
  operating-system matrix; local success is not a claim that remote CI finished.

Main evidence: `E:/BlurMask-build-artifacts-20261014/prior-structural-writer-root-20261029`.
The earlier staged 78-document pipeline is in `prior-dom-diff-next-20261029`.
The first admission attempt correctly rejected two newline-only byte differences;
repository LF sources were then rebuilt and authenticated rather than reusing a

## Next required path

Real changed-input recognition needs a stable raw-Ink authority retaining prefix
curve identities, a privately minted feature projection and proper INPUT/C22
replacement without mutating old canonical aliases. A new foreign Document or an
incremented numeric epoch is not that authority. Native source request tokens,
page observer counters and managed apply epochs are distinct domains. Temporary
application, late pending registration/resolution, stale removal and the actual
outgoing receiver must then be exercised with genuine kept actions. Existing
fresh guards must remain exact.
