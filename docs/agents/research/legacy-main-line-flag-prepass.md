# Owned multi-physical blank geometry and flag prepass

The additive `LegacyMainBlankTransitionGeometry` constructor accepts the actual
`LegacyFreshMainSingleLineSampled` owner. Its graph, guide, descriptor line,
ordinary bounds and all-predecessor prefix maxima come from that source. The
same pinned main297/v106 profile supplies threshold minus0.5, gap slope3 and the
disabled10C filter. No singleton source, first-model frame or replacement height
is manufactured. The earlier single-glyph constructor and `Source` property
retain their behavior; the multi-physical variant exposes `MainLineSource` and
explicitly refuses the old single-glyph property.

`LegacyNativeMainWordFlagPrepass` has an additive overload taking
`LegacyPreparedFreshMainLine240AcousticScorer`. The existing2136D0 path uses that
owner's graph, main context/classifier195 costs, category profile, geometry ink
and actual guide. Count-symbol qualification, kind5 request construction,
118/140 geometry calls,128 acoustic scoring,1F8D60 insertion, cache reuse and
failure/cancellation behavior share the original implementation. Parent rows,
source headers,22F7 flag polarity,58 distance and request residue remain explicit
prepared inputs. Automatic controller selection and the full scheduler are not
introduced by these overloads.

`tools/LegacyMainLineFlagPrepass.Probe` constructs the actual14-physical fixture
from [the owned ingress audit](legacy-main-single-line-ingress.md). It checks412
nonroot gap costs independently from current bounds, every predecessor prefix,
the real guide and the lookup/rounding equation. The genuine dictionary/mask/D0
preparation returns ten root source records, all consumed without selecting a
known label. Native initial processing emits12 parents; an actual emitted
parent enters the flag prepass. Its geometry, count-symbol acoustic cost and
separation cost produce one complete128-byte record, independently checked
including allocation residue and parent/tag/ordinal fields. The probe also
checks flag-polarity skip, distance equality, bad residue, wrong source getter,
cancellation and failed-producer invalidation.

The first-model setup remains the same explicitly scoped diagnostic fixture as
the ingress probe. The test does not provide expected OCR labels or claim a full
word winner. A caller flag is intentionally inverted relative to the actual
stored parent's flag to exercise the existing prepared consumer; this is not a
claim that a live fresh controller invokes that branch for every initial row.
