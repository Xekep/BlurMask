# Initial quote and primitive candidates

`LegacyNativeMainInitialSpecialCandidates` restores the ordinary, nontracing
`1FD240` single-context branch over `LegacyOwnedMainWordSpanPreparation`.
It includes apostrophe/quote handling and the literal primitive-extra record
decision. This is a bounded consumer of **explicit prepared source pages**;
it does not manufacture decorator or protocol query records.

The main graph, 195-entry class cache, finite-union qualifier, symbolic context
container, category profile and prepared source header table belong to the same
owned D0 preparation. The internal `ValidateSpan` guard is additive and runs
before any data callback, including for an empty page. Stale/foreign epochs,
exceptions or cancellation invalidate the candidate producer. The original
frozen default fixture remains unchanged.

## Static branch evidence

`20C1C0` resolves these exact alphabet symbols:

| Controller field | Symbol |
|---|---|
| `24BA/24BC` | apostrophe / quote |
| `24DC/24E2` | F0001 / shadda, skipped before context/header lookup |
| `24DE` | ZWNJ |
| `24EC/24EE/24F0/24F2` | F0002 / F0003 / F0004 / F0008 |

Absent symbols remain FFFF. The actual RU primitive labels are 187/188/FFFF/FFFF.
The explicit selected-source header table includes the proven fresh implicit
descriptor at index zero as well as dictionary index one.

The supported single initial context is grafted under the actual FFFA sentinel.
Its parent is therefore FFFA, rather than the special ZWNJ context examined by
the first quote rewrite. With associated controller `2300` absent, quote
variants use normal start/end category maps. Apostrophe and quote force two
variant attempts even when input bit `10` requests only one. The native ending
map may be absent; the actual resource has ending map -1 for both quote labels,
so that second attempt stops without an allocation. No synthetic ending entry
is installed to make this visible as an extra record.

Scoring uses the exact complete startup packet and the same owned final cache
as D0. All normal initializer fields, FFFA context ownership and graph-root
ordinal order pass through the existing native writer/router.

For primitives, frontend `B8 = 152040` resolves graph `68` then reads graph `88`.
The restored ordinary graph producers initialize kind zero. Native `1FD240`
emits a second record when B8 is zero, mode `22F6` is false, aggregate `22E8`
low three bits exceed one, and the label matches one of the four resolved
primitive labels. FFFF does not match. `LegacyNativeInitialPrimitiveExtraRecord`
copies the already scored record, subtracts the original query base cost with
signed-32 wrap, forces count/state-bit6 to zero and state-bit7 to one, and keeps
the original accumulated increment/context/category/anchors. The consumer also
updates the live cost cell before that allocation. Heap-budget rejection skips
either allocation without treating the native routine as failed.

`20BAA0` initializes query capacity `1684` to 128 and the extra-cost pointer
`1678`; this is distinct from frontend C8's 125 word-row budget. The probe reads
actual pages at capacity 128 and checks the 12 zero extra-cost bytes per row.
Outer scheduler/pagination construction remains a separate caller stage.

## Remaining producers

The supported branch has ordinary frontend280=false, input-method2601=false,
mode22F6=false, tracing2368=false and no associated2300 quote rewrite. General
context/control-token expansion, ZWNJ context rewrites, active associated2300,
case/decorator290/292 factories and protocol FFE3..FFEA source58 expansion still
need their actual producers. Their pages are not silently flattened here.

The actual direct LK alphabet contains no F0002/3/4/8. Its prepared linguistic
mask accordingly leaves 187/188 inactive; the ordinary mask producer restores
the prototype header, rather than inventing those four active symbols. This
batch therefore checks the primitive writer against independently prepared
scored controls, **not** against falsely enabled actual NN outputs. Real
primitive-query generation and mask ownership remain a specific dependency of
the outer decorator/protocol source. No masks, class costs or expected text are
overridden to claim that integration complete.

The supplied explicit pages must retain their actual source/context provenance.
The consumer validates its D0 owner and symbolic fields; it does not prove that
arbitrary supplied bytes came from a missing source factory. The real-resource
tests exclusively use pages read from the owned direct dictionary.
