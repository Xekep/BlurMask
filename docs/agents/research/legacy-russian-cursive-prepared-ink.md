# Raw points and inserted native sampler297 cuts

`LegacyCursivePreparedInk` restores point-record preparation from native `180191950` and insertion from `18018dde0`. It uses owned float coordinates and preserves a map to global original raw-point indices. It is one required layer of the continuous cut producer; it does not yet select every native cut location.

The initial prepared buffer is a flattened copy of raw strokes. Each28-byte native record contains X, Y, next dx, next dy, next segment length, typed tag and physical stroke index. Deltas are computed across the entire selected flattened buffer, including inter-stroke gaps; the final global record has zero deltas and length. Each physical stroke's first record receives tag1. The associated original-point map starts with sequential global point indices.

Segment length is proven, rather than inferred: native `18025bab0` is the CRT `_hypotf` implementation. Already rounded float deltas are promoted to double, squared and added in double, passed through sqrt and rounded back to float. Squaring deltas directly in float is incorrect and can overflow for otherwise representable distances. The independent implementation rejects nonfinite points, overflow and more than4096 prepared points instead of invoking native error callbacks.

`18018dde0` inserts an explicitly supplied float point and tag inside a physical stroke. It updates the preceding record's forward delta/length and the new record's forward delta/length. Following records keep their existing geometry and tags. It duplicates the preceding original-point-map entry for the insertion. Native geometry chooses where to insert and updates cumulative stroke starts; the independent buffer updates its owned stroke counts. The caller supplies a proven cut position; this API does not guess locations.

This establishes an important source distinction. Some `191950` geometry branches insert synthetic points. Final markers refer to local indices of these **prepared strokes**. Native `193380` passes that prepared ink to its service, and `1935e0` creates atom ranges against those prepared counts. Therefore callers must pass prepared counts to `LegacyCursiveInkAtoms.Build` and apply resulting ranges to `ToStrokes()`. Applying prepared markers to unchanged original raw ink may select incorrect coordinates or fail bounds. The raw-index map is available for tracking provenance and contains duplicate indices at inserted points.

The console probe supplies original controls plus512 independent float-bit record chains, each with one to five insertions. It checks inter-stroke deltas, double hypot rounding, copied coordinates/counts, inserted mapping, preservation of unrelated records, and the complete prepared-ink → markers → atoms → composed ranges → copied float glyph handoff. Managed and Windows NativeAOT console runs are required before marking the component ready. Full native candidate-location geometry, especially `18018e960`, remains separate work.
