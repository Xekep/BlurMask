# Owned first-pass interior delimiter

`LegacyFirstOwnedInteriorDelimiter` restores the ordinary assigned-source
`1F42D0` interior request to frontend1A0 and graph21B/1AAE70. It binds the actual
`LegacyFreshFirstOwnedRecognition`, its private factory, cut coordinates and graph,
the selected first sampler categories and the real24A guide. It does not borrow
a main-source frame or accept a caller-supplied separator decision.

The first caller supplies kind1, policy0, source-gap0, special scalars0 and no
before/after neighbors. The seven-category matrix, punctuation/dash rules, graph
start-context handling and current-arc fallback flag determine whether the result
contains the actual protocol tokenFFFB or zero tokens. A zero-token result retains
FFFF as its unused symbol scalar. Component/external flags remain0 for this
ordinary no-metadata path.

The assigned descriptor line0 excludes the branch requiring both descriptors to
be unassigned. In particular, the implementation does not pretend that graph1D9
is false: its initializer reads container+8 bit4, which is set by the new-container
constructor. Graph9=1 excludes the alphabet cased-symbol adjustment. The validated
version106 sampler has no custom VE0 geometry branch. Bounds are measured from
the actual prepared cut points, separately from acoustic normalization rectangles.

The probe runs6144 prepared arc/symbol requests over three actual first NN/cut
graphs. An independent Python reader extracts the first alphabet and category
mapping directly from AK, recomputes182 group boxes from their source ranges and
point buffers, and verifies all decisions.27 invalid-domain/resource/cancellation
guards are checked. These are prepared callback controls, not an assertion that
all requests were emitted by a selected native word path or that Russian/English
text was recognized correctly. The existing numerical threshold kernel also
retains its separate independent main-interior controls.

This component is the dependency for the new first plain TEXT materializer. It
does not itself split selected traces, reset WORD276, publish words, create720
rows or close the empty-first24A lifecycle. The existing single-word API keeps its
strict boundary refusal.

Run `LegacyFirstInteriorDelimiter.Probe` with AK, engine profile, separation
profile and capture path. Run its `audit_output.py` with AK and capture. The
optional `tools/handwriting/audit_first_interior_delimiter.py --output <report>`
reads the pinned PE statically and executes no vendor DLL.
