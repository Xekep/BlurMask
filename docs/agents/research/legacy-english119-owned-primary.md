# Owned FIRST119 primary rows

`LegacyOwnedEnglish119FirstPrimary.Prepare(actualControllerCosts, nativeTable)`
derives the primary requests and geometry from the same English119 cache,
confidence, source247, sampler108, pruned graph and original point chronology.
`Run()` returns `LegacyEnglish119PrimaryResult`: a completed same-owner
40-byte primary98 recurrence, with detached row-copy access. It does not run
B0/B8, terminal273 selection or word/text publication. A primary best path
is not a final FIRST winner, accepted text or an accuracy result.

The [pinned native ownership plan](legacy-english119-primary-plan.md) closes
the first210 writer, actual negative source9C, absent boundary networks,
217-label category domains, blank5 and retained-root ancestor behavior. The
public factory accepts no replacement graph, labels, masks, class costs,
probabilities, source flags or expected text. The internal source-range getter
returns the existing owning graph; no seed IDs or document IDs are fabricated.
The private fresh policy reads B8/BA/header/category fields from its real
selected249/119 model. Old RU110/297106 factories are never substituted.

The existing `LegacyFreshFirstBlankPrimary.RunCore` numerical body was moved
unchanged into an internal shared kernel. Its normalized body SHA256 is
`9f376964237c202e0e5e1c5b11bb7a9744201116c642f72c1dff2c4b66145bd0`.
Only the two geometry method references become delegate parameters; the old
wrapper supplies the same geometry instance. The old public constructors,
request order, stable insertion, observer ordering and row-copy semantics
remain unchanged. The new owning adapter is the other production caller.

English requests retain native node/span/arc/top20/start-then-end order and
duplicates, exclusions, fallback placement and real1C13A0 prototype costs.
The index starts at zero (1EF63F/641), increments at1EF95C and is passed
to frontend160 at1EF96B/974 with the20-entry limit at1EF94E.
Regular requests retain the actual top20 ordinal; the synthetic blank alone
uses FFFF lookup. Native stores at1EF831/1EF8D6 versus1EFAAE feed param9,
which1EE493/1EE49A places at class-request+6. The geometry prototype is the
resolved category78 entry, not the composite ID or first-map index. The
independent capture checks every actual ordinal/prototype request separately.
Candidate24.field0 supplies the quantized likelihood byte, independently of
calibrated vector10[0]. All same-owner cached NN objects are reused. Native
1941B0 reverse/forward caches use post-cut XY and source height;108 margins,
pair parameters and caps come from the English wire owner. Prototype and
composite/FirstId domains remain distinct. Kind0/2/5/6 and the replacement
short circuits preserve their own costs and limits, including negative pair
offsets. Original acoustic parents remain separate from geometry ancestors.

The scope is a NEW, unscoped ordinary selected249 source without external or
reused configuration, prior pages, property events, Arabic-derived traits,
suppressed/type1/type2 source groups or custom134/1D0 boundary networks. The
existing candidate/cache factories already validate the actual immutable
English AL and supported119 network/profile branches. No code enables these
conditions with a caller boolean. Unsupported profiles fail before a primary
result is published. Checked integer arithmetic,4096 logical nodes,131072
arcs, native bounded span/beam fields and a1,000,000 proposal cap are explicit
portable bounds. A per-node U16 arc-count preflight prevents ordinal wrapping. Allocation addresses and allocator failures are not emulated.

`Run` installs its immutable result only after completion. Observed runs use
private row storage; cancellation/observer exceptions may expose the already
reported scalar prefix but cannot publish a partial owning result. Cached NN
prefixes remain reusable. A valid later run is verified after failures at the
twentieth actual callback. Observers receive value snapshots and cannot return
success flags or costs. The existing record-table storage/opaque-byte policy
is retained; captures are portable owned rows, not raw native memory addresses.

The probe uses124 real raw inputs and their previously audited candidate and
controller-cost captures. Actual execution produces43267 proposals,3850
primary records,534740 ordered geometry callbacks, one retained blank row and
46 callback observations with skipped ancestors. These are engine coverage
counts, not English handwriting quality. The independent stdlib oracle reads
the original sampler/category bytes, validates source/cut/cache identities,
recomputes float geometry, replays every callback in order, and compares every
byte of every primary record slot. No expected word enters inference.

Separately labeled512 prepared numeric controls use a genuine four-physical
source/graph but supply explicit requests, costs and a root-header category
override. They cover1280 skipped-ancestor observations and256 retained-root
observations. These controls exercise the internal numeric kernel; they are
not presented as outputs of the public scheduler. Guards include cancellation,
callback failure prefixes, recovery without another NN, detached arrays and
resource/ownership scope. Old57-NN primary and full-context captures are rerun
in Managed and fresh Native AOT before freezing this batch.

Generate controls with `reference_controls.py controls.json`. Probe arguments:
`models-directory actual-controller-costs.json controls.json output.json`.

isolated mode and an unrelated working directory; no ignored research module
is used by that numerical audit. Static composition lives in
