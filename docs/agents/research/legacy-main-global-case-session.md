# Global ordinary graph cache and case-query session

`LegacyFreshMainGlobalCaseSession.Prepare` connects the actual shared global graph
to one fresh case-symbol binding, one192-label acoustic source and one292 dictionary
backend. It consumes the actual owned global geometry and pinned AK/LK/model pair.
No same-source candidate graph, seed membership, document-object ID or parallel
DIRECT backend is manufactured.

The internal `LegacyOrdinaryRecognitionGraph` accepts only the existing same-source
candidate producer or the actual cross-merged/pruned compact producer. It retains
the real owner identity and snapshots the group/span fields used by the query and
cache kernels. Native21B38/60/68/70/1C8 getter bindings are shared by both producers.
The older public concrete APIs and their graph getters retain their original
same-source type; the new internal global path cannot return a fabricated value
from those getters.

The existing ordinary pooled-cache and frontend qualifier kernels now have internal
graph-bound cores. Their original constructors adapt their existing callbacks.
The global owner computes actual final195 costs on demand and retains private
copies only. Public cost/permission/map/eligibility diagnostics are copies. Public
acoustic scorer results, whose memory buffers can be recovered, are never retained
as mutable cache storage.

The owning caller explicitly advances V80 at−1 and after every completed node.
It supplies ascending D0 spans within the actual frontend98 extent, including empty
intermediate spans. D0 computes or reuses selected cost rows, produces acoustic
permission bytes, then applies234840→093F80 exactly once to the shared case backend.
Refreshing permissions never resets the query slots. A span records its owner,
epoch and actual installed map. Stale or foreign spans cannot query that backend.
The existing normal50 key progression, immutable auxiliary60 behavior and full-tag
metadata/restart paths are preserved. Query context ownership is checked explicitly.

The probe prepares eight actual raw inputs through first TEXT→720, guides, shared
descriptor cuts, local allocation, cross merge/prune, compact selectors, global
source120/context227 and acoustic producers. It executes638 ordered D0 spans and
631 actual four-family/cache evaluations. This input set has no repeated selected
group IDs in a cache span, so its native pool-reuse count is zero; repeated normal
and normal/auxiliary/normal query calls perform no further network evaluations.
The existing independent6144 prepared cache/qualifier passes exercise reuse and
invalidation separately. Source-level root-page exercises produce27,734 case-aware
records;1,922 checks cover stale spans, context guards, cancellation and defensive
copies. These prepared root-query calls at each D0 key are not claimed to be requests
emitted by the complete word scheduler.

Python checks the ordered pool transitions, aligns every selected cost row with
the independently audited actual global acoustic capture, recomputes finite-cost
permissions, ordered stored-case propagation and the lexical working map, then
independently expands all root records with full source stamping/context ownership.
The old292 session, persistent case-span keys and qualifier kernels retain their
original Managed/Native regressions. Static audits pin the native cache/source
functions and ordinary graph slots, plus the existing V80, key and factory proofs.

The next integration boundary is global word geometry and the complete controller
over this source. This adapter does not yet provide native word-category geometry,
main pass, final winner or multiline text publication; it is not an OCR accuracy
claim or an application-ready multiline recognizer.

Probe arguments: AK, engine, separation, case, publication, line30, line50,
capture, LK. Audit arguments: AK, LK, independent case-preparation-controls,
actual-global-acoustic-capture, session-capture. The case controls are generated
by the existing `LegacyCaseAlphabetRanges.Probe/reference_controls.py` and
