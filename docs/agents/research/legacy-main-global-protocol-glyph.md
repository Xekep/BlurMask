same source callbacks, headers and graph. The request64 numeric kernel is shared
with existing DIRECT/CASE callers; no old dictionary or graph owner is created.

The caller builds every native request field while preserving explicit stack
residue, including compact-neighbor header class, hyphen lookbehind, source

cursor after exhaustion without additional writes. The shared caller writes

single-control pending contexts; multiple-control underflow is tested separately
through the internal numeric writer. These prepared controls are not reported
