## Sparse numerics and written bytes

The service reads packed word classes/row offsets/sorted labels directly from
the immutable language wire. It searches longest suffix first, adds backoff
only for the exact reached prefix, drops missing prefixes without inventing a
penalty, and adds the actual word-specific code cost and explicit boundary
cost. Source135/profile2, scale1, Context00=IMP and literal packet0 are required.
No optional compression, case/category policy or auxiliary vocabulary is guessed.
V60/V70 and unsupported category/option/trace paths have no adapter here.

Matched order at record+4 and retained history count at byte+8 are distinct.
The native40-byte mask covers+0..+8, only active history words at+C/+10,

no public result. All actual tested terminal costs are admitted naturally.
