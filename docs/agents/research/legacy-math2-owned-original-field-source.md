# Owned Math field and C23 before NN

`Math2Mode0OriginalMathFieldSource` supplies one library-owned original
mathField/INPUT102 and its worker-selected clone **before** inference. The
named `Math2Mode0RawOnlySource.PrepareColdWithSelectedMathField` consumes that
exact context and its original Document. It does not run the old stroke-list
factory and reattach a same-shaped document after NN.

This is an internal library scope. It does not construct a native SDK page,
CBB/store/revision/history receiver, CB8 edit, DOM publication or accepted
formula. It restores one selected worker pair; native00D540's dual-worker
orchestration and original-page history application remain separate work.

## Original, selected and native input domains

Preparation accepts the same immutable ordinary raw CurrentView and one
bounded caller field id. A new PAGE/content/layout contains an actual
mathField/id/input/tag. Math type13B9's registered namespace marker and C98.kind2
justify INPUT category102; no public kind, category or success flag is input.
The container node kind4 is a generic library DOM root, not Math field kind2
or a coerced text target. Old text bootstrap/selected APIs are not used.

The actual private C51 registry stores a complete signed64-bit key, nameINPUT,
category102 and an owner-bound C22. Fresh registration assigns0 and Next1.
The selected clone keeps those values and constructs its own C20/C22 objects.
Original raw source slots remain0..N-1 and are not the registry id. The selected
field's cloned nodes retain original-node identities. Original and selected
name pools are separate generic library BEE owners; equal names are canonical
within their owner, not global native addresses. This reuses the generic name
token class without a text field/bootstrap owner.

C23 has its own identity and begins with null/empty storage. Its C43 attachment
is the pinned no-op and supplies no domain. DAF lookup walks the actual
selected input/tag and SAME selected registry. The returned C22 must belong
to that selected C20. Mode0 preserves its ptr/count early return, then copies
the selected C20's domain and uses the already verified native range
intersection with the actual INPUT. Complete ordinary raw coverage is checked
through the same CurrentView exporter before NN is enabled.

The positive factory has one full nonempty INPUT102 only. It refuses partial
coverage rather than computing complete features for a partial C23. Missing
input/tag, missing registry, tag2^32 colliding in low32 bits with existing0,
null-empty/allocated-empty and partial intersection are explicit friend-only
prepared controls. They cannot authorize the full-source NN route. An empty
C23 remains a no-NN state, not a fallback to all strokes.

The numerical and coordinate contract is
[the static original field/source proof](legacy-math2-original-field-source.md).
No nondefault namespace/property/imported-field/C25/guide/activeArea/prior-result or
multi-F0 branch is inferred from this narrow producer.

## Claim, budget and source lifetime

The context preflights the actual immutable raw extents and a conservative
16MiB retained-payload envelope before building any field nodes. Its added
reservation includes the CurrentView's XY copy, two bounded DOM/registry name
and entry allowances, and four range vectors. The Document's original XY and
processed positions are reserved once by the existing mapped-position owner.
The field addition is propagated into that owner's reservation, so source
attachment, first-copy and outer-copy budgets continue to include it.

Before the inference claim, the named source factory checks the combined
field/Document/maximum processed-position envelope. It then claims the actual
field/C23 once, prepares features from that SAME Document, revalidates the
binding and only then allocates source/downsampling/strk_ends tensors. Existing
ColdBundle verifies the raw resource,297 labels and all three graph hashes.
The source retains a private binding with exact field/context/C23 identity.
There is no reverse context-to-source or context-to-decoder reference.

These bounds describe the named retained payload, not process RSS, CLR object
headers, ONNX model weights or native allocation order. Managed logical
original/selected objects share the immutable source Document; the full native
C20 allocation/observer graph and history manager are not recreated. Native
partial allocator failure order is not claimed.

Preentry cancellation or unsupported shape does not claim inference. An
entered construction fault preserves its semantic node/registry/range prefix
and marks the context failed. Failure after the inference claim also marks it
failed and prevents retry. Cancellation and scope close are checked at
operation boundaries. Closing a context revokes new source/output/receipt
operations; source disposal still releases its own model/history payloads.
This is not a new guarantee that closing metadata asynchronously interrupts an
already running official-ORT call.

## Produced scoped first-copy receipt

`actualSourceBoundOutput.CopySelectedMathField(actualContext)` validates the
same successful output attachment under its existing owner gate, then reads
the source's exact private field binding. Document equality is checked as an
additional invariant and never substitutes for that binding. The method
performs the existing first-copy operation and privately constructs a
`Math2Mode0SelectedMathFieldCopy` receipt.

The receipt retains only that detached first copy and the scoped field
binding. It retains no SourceBoundOutput, NN source, Step, decoder or model.
Its validation requires the exact produced copy and context, a live completed
copy pool and the same active inference binding. A different field context
on the SAME Document, even with the same field id and identical ranges, is
rejected. Scope close revokes the receipt's authority without erasing the
already detached copy's immutable inspection data.

The ordinary first-copy/outer APIs stay unchanged. Their Document-only objects
do not themselves authorize a Math field or DOM operation. A later math DOM
publisher must consume the explicit scoped receipt and corresponding selected
owners. No caller can create this receipt from an arbitrary detached copy.

## Verification

`LegacyMathOriginalFieldSource.Probe` runs actual official Microsoft ONNX
Runtime1.23.2 with the fingerprinted Math2 bundle. Two inputs preserve and
reverse original physical order. Each traverses original mathField/INPUT102,
selected clone/C23, the same source-aware NN/full EE4, source ranges,
first-copy and one-source outer vector. Expected transcription is never read.
The actual NN raw-attention hashes remain identical under physical reversal
when MeanX restores the same feature order; C79 ranges still use the correct
different original source IDs. Copy/publication performs no additional NN.

Checks include7 prepared C23 branch controls,22 explicit throw/cancel semantic
construction prefixes and69 guards. Same-Document foreign fields/copies, a field created after old raw inference, forged
binding, replay, cancellation, exact/one-below budgets, close during callbacks,
scope close and a disposed official-ORT run are covered. The latter is an
external lifetime failure after claim, not a vendor allocator failure model.
All prefixes remain poisoned. Source preparation cannot be retried.

The independent tracked Python oracle reconstructs PAGE/field nodes and clone
origins, tag/Next/category, full C23 selection and each failure prefix. It also
derives features/positions from raw points, run ranges through independent
C21 union, UTF8 intervals from raw AL and separate first-copy/outer pool
identities. Feature error is0 on the tested host. Forced GC proves the scoped
receipt/context does not retain the disposed decoder; retaining the actual
source-backed output is the positive retention control.
