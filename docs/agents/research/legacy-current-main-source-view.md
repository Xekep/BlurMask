# Current main source metadata view

`LegacyMainFirstResultLineController.PrepareOwnedCurrentSource` prepares the
resource-owned24B controller from the typed main15B260/15F050 result. It reuses
that result's current retained physical point order, probabilities and original
point chronology. It does not rerun167210's source filter or2AD enclosure, and it
does not import a first-child frame as a main guide.

The new internal `LegacyOrdinarySourceInk.CreateOwnedMainPhysicalReorderedView`
can only consume that actual reorder owner. It checks the complete physical
permutation, every current point/probability against its original owner and every
resolved original key/metadata index. Original point-index arrays and raw counts
are permuted to describe the current physical arrays. The current factor200
chronology remains the same actual owned object; original key.Second retains the
original raw physical ordinal, even when the current physical position differs.

That distinction is essential to ending metadata. The source218 end-key producer
uses the original raw-point owner's next retained ordinal minus1, or its original
raw count minus1. A current physical index cannot index the original raw metadata
array after a reorder. `ResolveEndingMetadata` therefore forwards to the actual
original metadata owner for this view. The original `Prepare` path still owns its
own metadata and retains its previous behavior, profile reader and filtering.

44 actual-model input cases verify1453 start/end identities,106 changed physical
positions and21 cases with differing original raw counts. Native and Managed
agree. They check every original endpoint against the independent raw input
count/index rule, not just equal copied point arrays. The original512 independent
raw-adjacency/map/chronology controls,12 resource profiles/truncations and actual
RU source/enclosure roundtrip also pass in both execution modes.

This is the owning current-buffer bridge for249 submissions and24B. It does not
select first words, create caller-supplied rows/guides, run general24D/29B or claim
that all SDK/inherited callback and final decoder boundaries are complete. The
source view deliberately retains original key identities alongside current
physical arrays; these two coordinate domains are not interchangeable.
