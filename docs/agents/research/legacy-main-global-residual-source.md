# Global per-flush residual sources and V140 metadata

`LegacyFreshMainGlobalResidualSource` is an owning ordinary `1AC3C0` overlay on
the real shared compact graph. It binds the actual global source geometry,
policy, dictionary context and confidence owner. It creates node-local higher
source records, not new global neural groups. Their ranges/capacity and
`originalLast` are private owned data; no native pointers or opaque bytes are
invented. Bounds, line, top-mark and neural identity resolve through the
original last base reference. Source membership is a separate result.

The merge preserves native middle-pivot `(physical,start)` ordering and equal
key swaps, shared-endpoint-only coalescing, capacity growth before coalescing,
last-node exact-range cache, first matching global group and all-node context
endpoint scan. Count1 preserves all input64 bits after ownership validation.
Multiple inputs containing a higher source remain unsupported: native directly
indexes base arc arrays before searching extras. Portable limits are 65536
references/extras and 1048576 concatenated/stored ranges, as on the old owner.
They are implementation budgets, not native allocator constants.

`LegacyFreshMainGlobalGlyphAssociationSession.Prepare(plan,geometry)` retains
the real flush plan. `PrepareNext` passes exactly one native flush to the
existing `217DB0` kernel. It appends new residual additions to only the old
remaining prefix and preserves the returned storage and count separately.
The session blocks re-entry until the current association is acknowledged.
Acknowledgement is internal: no public success bool can manufacture executed
publication. The owning global `218560` callback is a later integration;
the probe acknowledges explicitly prepared outcomes to check chronology.
Cancellation after mutation leaves the session stopped, retaining prefix
effects. Fresh no-external-property knowledge99=false and source135/C1=false
are the existing owning policy scopes, not general SDK invocation defaults.

`LegacyFreshMainGlobalGlyphSourceMetadata.Read(key)` implements ordinary
`21B.V140=1AA470`. A base key resolves the actual start/end context interval
with the existing shared-graph span0/selector1 DFS. A higher-kind0 source
projects its stored ranges directly through that same source's prepared point
chronology, original F8 keys and source108 ending metadata. The two paths must
not be substituted for each other. The target key remains distinct from the
base scoring key. Output storage is `24*N` source records followed by `2*N`
endpoint bytes. Negative/protocol refs, alternative ordinals and noncanonical
originalLast are outside this bounded metadata owner. This portable domain is
not a claim that native1AA470 rejects every such ushort.
Graph nodes and descriptor ordinals remain graph/source identities; the raw
source keys come from the retained original point owner. They are never
reinterpreted as document object IDs or independently resampled line indices.

The higher-range projection is a shared internal kernel extracted from the
previous single-source metadata implementation without changing its algorithm.
The old public APIs and captured metadata are regression gates. The global
geometry addition is only an internal no-allocation range comparison; its
public API and live geometry remain unchanged.
