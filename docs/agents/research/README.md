Файлы `legacy-*` описывают форматы, владельцев и восстановленные операции; `english-*`, `russian-*`, `linguistic-*` и датированные отчёты — отдельные пути и контрольные прогоны. Полный набор можно искать по имени или символу:

```powershell
rg --files docs/agents/research
rg -n "LegacyEnglishCaseNode0Completion" docs/agents/research src/InkRecognition
```

Пути к внешним артефактам и хеши сохраняют происхождение проверки. Отсутствующий артефакт нельзя заменять похожим файлом без нового доказательства. Количество пройденных числовых контролей не является оценкой качества распознавания.
