# Native loop-cut preparation

`LegacyCursiveLoopCuts` restores complete stage `18018e1f0`, finite-segment intersection helper `18018db40`, and double insertion `18018df60` through the owned prepared buffer. It processes one physical stroke and keeps all other prepared strokes unchanged. It is still a stage of the unfinished `191950` controller.

The native scan considers nonadjacent segment pairs in original prepared-point order. Inclusive bounding boxes prune impossible pairs. The intersection helper evaluates its determinant, line constants and coordinates in float32, rejects determinants strictly below1e-10, and applies inclusive segment bounds without enlarging them. The output coordinate ordering was verified against instructions18e3ce–18e417: local_f4 receives X and local_f8 receives Y.

For an intersecting pair, native geometry counts spaced directional reversals independently on X and Y. Zero deltas preserve direction; minimum spacing uses strict greater-than. The previous-position sentinel is exactly−1, including its behavior when an actual reversal coordinate equals−1. More than two reversals on either axis rejects the loop. Normalized adjacent-segment cross products accumulate in float32 and determine loop orientation. Russian sampler297 field+30 supplies spacing0.1, verified in both version106 serialized nodes.

Double insertion places the same intersection inside both segments. The new points receive tags11 and12 and copy the preceding original-point identities. End-first insertion followed by start insertion reproduces the native memmoves and mapping. Only affected neighboring deltas and lengths are recomputed. The scan then advances by the exact native two-point adjustment before its ordinary outer increment.

Interior tags follow the recovered orientation and nesting rules. Negative turns mark unassigned points13 and also replace7/8 when no earlier loop tags are present. Nonnegative nested loops replace only unassigned points14. Nonnegative unnested loops map7 to9 and all other interior tags to14. The inserted boundary tags are excluded from the nesting test and interior rewrite. These kinds stay opaque; the implementation does not name them as letters or introduce recognition heuristics.

`tools/LegacyCursiveLoops.Probe/reference_controls.py` creates768 independent finite-ink reference cases with varying physical strokes, nested tags and spacing thresholds. Controls compare all resulting float coordinate/delta/length bits, tags, source stroke IDs, original-point mappings and prepared counts. Additional controls verify both turn signs, nested preservation,7→9 behavior, determinant equality and the immediately smaller float cutoff, parallel segments, endpoint bounds, immutability, malformed input and cancellation. The optional resource argument verifies actual Russian spacing bytes. Managed and Windows NativeAOT console runs are required before marking this stage ready.

This stage inserts prepared points and must precede the horizontal `18018e960` stage. It does not select the baseline-crossing cuts `180190350`, final marker limits `180191430`, the override geometry `1801908c0`, or the full runtime branching in `191950`. Its passing controls establish bounded branch arithmetic and provenance, not full-engine parity or Russian handwriting accuracy.
