# Bounded no-candidate source completion

`LegacyFreshMainNoCandidateSourceCompletion` joins TOP.V68 for the actual fresh
one-alternative, one-WORD, singleton275 entry whose active compact pool contains
no bit8 candidate. This is a genuine observed native branch, not a manufactured
empty list or suppression of candidates. Enabled augmentation is explicitly
refused if **any** active compact row has bit8.

The owner retains the actual219580 source count/fill26N sidecar, source graph,
WORD node and first-alternative ownership. It joins prepared13D360 ranking to
the real275 replacement/279-index patch, then mandatory275.V08/140B90 to the
actual WORD score fields. Singleton ranking invokes no276.V60 comparison;
an unexpected comparison throws instead of supplying a fabricated equality.

The final13D000 guard is bound to the same primary AL: U+2610/U+2611/U+2612
are all absent. Its selected label must be nonFFFF before matching any lookup,
so this native checkbox rewrite cannot execute. The fresh frontendV228 callback
has a null v106 preparation hook and only invalidates the acoustic last-group
optimization. Existing portable scoring uses immutable inputs, so no numerical
state or source overlay is replaced by that invalidation.

The prefix-only `LegacyOwnedMainWordSourceCollection.IsTopV68Completed` remains
false. Only the new owner reports completion after source marking, actual rank
replacement, actual score publication and the checkbox guard all succeed.
An entered failure poisons the owner; the already-applied prefix is retained.
The claim is shared by the actual TOP, preventing a second wrapper from silently
rerunning completion. Entry cancellation leaves the prepared invocation usable.

This is **not** a general219580 or TOP.V68 implementation. Multiple active
alternatives, non-singleton275 entries, bit8 candidates, enabled checkbox
rewrites and external/property/reuse branches remain separate. It also does not
implement0283B0 document orchestration, accepted transcription or application
recognition confidence. Russian cursive quality is not declared complete.

The probe runs seven original raw inputs and can separately run the existing
nine recorded word tracks without reading expected labels. It captures every
active compact row to prove that bit8 is absent, complete before/after WORD
payloads, references and actual26N source storage. The independent oracle checks
the entire120-byte transformation, unchanged references, source extents and
primary-AL checkbox absence. Existing static lifecycle, lazy-preparation,
ranking/span-storage and score-finalizer audits support the composition.

```
LegacyMainNoCandidateSources.Probe AK LK engine separation case publication line30 line50 capture.json
LegacyMainNoCandidateSources.Probe AK LK engine separation case publication line30 line50 capture.json --recorded manifest.json
python tools/LegacyMainNoCandidateSources.Probe/audit_output.py capture.json
```

## Concurrent entry to global callback completion

The separate `LegacyFreshMainGlobalNoCandidateSourceCompletion.Run` now claims
entry with `Interlocked.CompareExchange` before its mutation/failure handler.
Two calls on that same wrapper cannot both start quote cleanup; the losing call
refuses before entering the failure handler and does not fault the winner.
This protects one wrapper. Coordination between distinct wrappers and the new
augmentation stage remains separate pending integration.

`tools/LegacyGlobalNoCandidateConcurrency.Probe` is an explicit headless actual
diagnostic. Its reviewed plan pins model/profile files and one original stroke;
the tool checks that the resulting compact pool genuinely has no eligible bit8
rows, then starts two dedicated workers on the same owner through a barrier.
It requires exactly one completion and one precise pre-entry refusal, unchanged
NN evaluation count, an unfaulted owner and an unstopped session. CI compiles
the harness; actual inference requires explicit `--actual PLAN CAPTURE`.

The controlled run on track0 observed2129 active compact rows and passed those
conditions. Full WORD120, Source26 and quota matched the separately recorded
old completion under the experimental shared-claim protocol byte for byte.
One concurrent pair establishes the observed lifecycle and output regression;
it is not a stress survey or a handwriting-quality result. The independent
capture auditor also rejects seven damaged payloads:

```
dotnet run --project tools/LegacyGlobalNoCandidateConcurrency.Probe -c Release -- --actual PLAN capture.json
python -I -B tools/LegacyGlobalNoCandidateConcurrency.Probe/audit_output.py capture.json report.json --baseline OLD_CAPTURE
```

The separate experimental augmentation harness passed five actual zero-eligible
lifecycle scenarios (success, cross-thread old completion, old failure, new quote
reentry failure and protocol fault). These are historical captures from before
the primary compact flag correction. Track0 now produces eligible records and
cannot be used to repeat the no-candidate concurrency test unchanged. That test
still requires a genuine source with no eligible records; input flags must not
be patched to manufacture one. The separately implemented
[owning augmentation path](legacy-global-word-augmentation.md) now has a bounded
positive actual entry. It does not turn the old no-candidate owner into an
eligible-word handler or establish a complete allocation/RSS guarantee.
