# Original raw global source views

`LegacyGlobalOrdinaryCroppedSource.Prepare` resolves the original CHAR and WORD
keys of the genuine completed global publication into numeric raw curve views.
It does not require WORD/TEXT coverage equality: MIR/II remain valid inputs to
this earlier geometric building block. No configured owner or original source
selection ID is manufactured. Native2DB boundaries and238B0 membership changes
are not implemented by this component.

Full original ranges retain C49 semantics. Integer cropped requests follow the
C4A start/count view; fractional requests follow C4B's float interpolation and
synthetic endpoints. The actual raw runtime V20 returns the same original curve,
and V28 resolves only the end-minus-one sentinel. C4B replaces a fractional
first point and appends a fractional last point; fractions use binary32
`byte * .005f`, followed by separate binary32 subtract/multiply/add per XY
channel. It does not interpolate an already computed bounding box. Endpoint
inclusion bytes are retained independently from point geometry.

The admitted raw objects and keys are derived from the same pre-NN INPUT/raw
document and typed global nodes. Known text, DOM/transformed sources and
unsupported range modes explicitly refuse. Whole preparation checks65536 views
and1048576 coordinate visits before point-array copies. Scope/producer/link/
pending-command ownership is checked before and after preparation. No original
flags, guide bytes, transaction commands or counters are changed. Cancellation
has no source rollback requirement. Result point/chunk copies are defensive;
closing the borrowed scope revokes live access. `ReadChunk` exposes bounded
20-point numeric copies, not a native buffer or allocator ABI.

Thirteen genuine inputs produce54 views and3014 XY points:23 full raw C49,
19 integer C4A and12 fractional C4B.217 guards cover incomplete producers,
cancellation, chunk limits and scope closure. Every output float bit and metadata
field is checked independently from the committed coordinate fixtures and the
separately audited actual source keys, including20-point chunk reconstruction.
The recorded corpus supplies no pen-up metadata; none is fabricated. This is
component equivalence for admitted finite raw inputs, not new recognition
quality evidence or complete source/object support.

Live operations also require the exact next selection counter and a healthy
transaction latch. A prepared failed registration that consumes a counter
without appending a command invalidates both the existing view owner and new
preparation. Checking only pending command identities would miss that prefix.
