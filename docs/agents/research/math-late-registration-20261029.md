## Native contract and owning implementation

Document028070 orders old-tag collection before the diff, applies its temporary
batch, resolves live negative tags, collects new tags and removes stale IDs.
The native pending list is prepended by033560 and searched head-first by0336C0;
the managed production-order list therefore searches backwards. The first match
is decisive, including duplicate IDs. A successful registration is cached before
the typed scalar write. Registration failure retains its negative cache; writer
failure retains completed registration.033870 preserves collection order and
rejects its exact minus-one sentinel;0339D0 performs ordered old-minus-new removal.

`Math2Mode0PriorLateRegistration` consumes the actual completed temporary owner.
Its private active grant is bound to the one claimed phase, exact temporary and
candidate borrows, ancestor locks and owning thread. Read borrows cannot mutate.
The factory installs the grant before observers run and clears it in `finally`.
There is no grant export API, so revocation of a captured actual grant is a static
source proof, not claimed runtime coverage. Direct/foreign/reentrant/expired
issuance refusals have separate controls. This prevents accidental internal
misuse; it is not a malicious-code security boundary.

Earlier draft v4/v5 did not protect the new mutator seam sufficiently. That
review conclusion was withdrawn; only corrected v6 is admitted. The first v4
runtime also stopped at a probe assertion which did not catch the existing
removed-ID `KeyNotFoundException`. Its logs were preserved. The correction adds
a narrow missing-ID assertion without widening the generic refusal helper.
