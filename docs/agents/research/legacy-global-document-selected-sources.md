# Actual global selected-source metadata

This NEW-only stage consumes the actual completed global document coverage,
retains its same scope, Seed, pending CHAR/WORD/TEXT prefix, original WORD and
complete CHAR interner, and produces an immutable01FD40/020000 overlay. No
configured-two-alternative owner, geometry owner, DOM or acceptance is created.

It accounts for every actual CHAR AVL node through the exact typed source
payloads in the actual global WORD links. Missing/unreferenced payloads refuse.
The complete AVL traverses in order with the native64-entry stack limit,
explicit cycle/missing/unreachable-node checks and original node identities.
The scalar/key snapshot budget is preflighted before copying the full arrays.

Native metadata guards stay lazy:10600000 skips prior/key predicates; unmasked
bit29 with selectionID-1 skips, while an actually used prior V128 owner refuses.
For an unmasked nonprior one-range key, the exact native U32/U16/byte predicate
decides whether C25 lookup is reached. That reached lookup refuses; ordinary
raw construction does not invent its concrete-kind result. All33 actual keys
in the supported corpus avoid the predicate. Prepared lazy controls are separate.

All supported CHAR metadata flags remain unchanged. WORD bit24 is recomputed
from every actual selected link's CHAR11004000 mask.020000 then ORs08000000 and
writes the signed marker44 in original link order, followed by the actual WORD
index0. The only reused numerical method is the existing internal
`LegacyFreshMainDocumentSelectedSources.ApplySelectedCharacters`; no old file
changes. Repeated source ordinals retain the final raw signed marker.

Original CHAR payloads, UTF8 rows, keys, source lines, WORD48 and pending commands
remain unchanged. The overlay retains captured metadata/scalars, string-owner
identities, complete keys, tree shape, WORD flags/selection/48 and next pending
counter. `Validate` rejects failed/intervening transactions, altered source rows,
changed WORD/tree state and disposed scopes. Cancellation before/during read-only
preparation returns no usable overlay and changes no native publication state.
Immutable scalar results may remain readable historically; borrowed source
content and current-owner validation retain their original scope lifetime.

The probe runs thirteen actual global sources: eleven exact-coverage owners
produce33 complete CHAR overlays and33 ordered writes; MIR/II retain the earlier
explicit238B0 coverage refusal. It captures full old CHAR40/UTF8 data, keys,
tree, flags/index44, WORD fields, pending IDs and source lines. An independent
Python oracle first checks raw CHAR, parent WORD/TEXT and coverage outputs, then
recomputes in-order traversal, exact lazy predicates, WORD metadata and ordered
writes. No expected labels enter inference.256 prepared alias controls,256 WORD
mask controls and14 lazy branch controls are separately labelled. There is no new natural reuse or
recognition-quality claim, and020920/source indices remain a separate next step.
