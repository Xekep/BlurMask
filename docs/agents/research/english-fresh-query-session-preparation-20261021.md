## Complete bounded work and memory

`LegacyEnglishQuerySessionBounds` explicitly limits future attempted insertions,
operations, output rows, retained checkpoints and additional logical bytes.
These are independent library limits, not SDK defaults. Preflight validates all
domains and the complete memory/work envelope before source allocation. Initial
source-map work is conservatively bounded by all104 lexical positions; the
actual source produces86 contexts. The live context bound is104 PLUS the
entire allowed future lookup count. The104 term bounds initial work only; it
does not impose a native-style total symbol/prefix limit.

The conservative envelope includes1KiB per possible live context for nodes,
dictionary growth and restore/copy workspace;128 bytes per context per retained
checkpoint;64 bytes per output for the complete32-byte row,12-byte extra-cost
record and headers;1KiB per bounded operation for cursor/maps/permission work;
and64KiB fixed space covering eight256-label slots,128x32 scratch, source
maps/identities, AVL stacks and headers. Existing N/M/P/L/V58 models are shared.
The probe's explicit bounds2048/512/8192/4 reserve4,419,584 logical bytes, below
the hard16MiB additional limit. This is not processRSS or a guarantee covering
arbitrarily many caller-retained defensive snapshots.

Read/lookup/operation/checkpoint limits are checked before mutation and consume
nothing on preentry refusal. Attempt counts include duplicate lookups. Work
counters are monotonic across restores; restoring a pool does not grant more
work. Page reads reserve their entire worst-case row/lookup capacity before
entry, including capacity for an unpublished partial page. Midoperation failure
poisons the owner and retains the committed prefix. There is no public callback
or allocator provider and no partial prepared owner is published on failure.

## Historical snapshots and prepared transport

The public defensive snapshot is historical diagnostic state, not an N request,
native pointer, D0 lease or source-query authority. It reports actual symbolic
nodes, AVL links/balances, separate symbol-parent and tree-owner links, pages,
source maps/source68 and work/fault/epoch fields. Returned arrays do not alias
the pool. Even a poisoned owner can expose its immutable diagnostic prefix.

The second library partial is explicitly INTERNAL PREPARED transport for tests.
It exercises the actual ordinary2B7 query ring/pages, root/child context lookup,
same-container checkpoints/restores and prepared permission changes. No public
API accepts its explicit IDs/flags/cursors. The direct2B7 writer emits full32
bytes with sourceID04=0; it is not the28D dispatcher that stamps sourceID1.
That actual dispatcher/request route remains unavailable until N's sealed
request/D0 lineage is accepted. No zero-filled80-byte controller request or
fake selected NN candidate is constructed.

Cancellation before an entered operation leaves counters/state intact. After
entry the operation counter is retained; a committed context insertion remains
even if cancellation precedes its separate parent-link write. Thus the oracle
can see a new node with tree-owner=parent and native parent-link0. After the
link boundary it sees the actual parent. A page increments the output count
only after the generic helper returns its complete page; a canceled lookup
publishes no partial scratch page. A cancel after the page boundary retains
its returned-row count while poisoning the session. These are library work
counters, not invented SDK scalar fields.

Checkpoint ownership is exact session reference identity. Restoring the same
pool preserves saved IDs and native descriptor capacity, removes newer nodes,
and makes removed opaque IDs stale. Future reused physical slots get new safe
portable IDs. The operation budget and global token sequence are not rewound.
Working50 refresh and query-ring reset are separate, as in native code:
refresh leaves source68 unchanged; pool restore does not silently reset working
maps or dictionary rings. The monotonic epoch is a library lifetime guard,
not a claim to reproduce a configured native controller epoch.
