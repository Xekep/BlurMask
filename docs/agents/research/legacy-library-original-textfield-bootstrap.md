# Original field and INPUT bootstrap

`LegacyLibraryOriginalTextFieldBootstrap.Prepare(actualCurrentView, fieldIds)`
creates a new library original-source owner before recognition. `Run()` retains
the same immutable raw document/current view, a PAGE tree, caller-named
textFields, original C51 entries and their retained C22 source identity. It does
not replace an existing selected INPUT or recognition Seed after publication.

The existing `LegacyFreshTextFieldInputContext` and publication APIs are
unchanged. This new entrypoint has not yet been adopted by their pre-NN
constructor path. It provides a concrete source/field producer for that join.

## Scope and ownership

The raw source is the complete checked ordinary XY current view. It is an
existing immutable starting source; the new journal does not invent earlier
raw-append history. The library creates its own fresh PAGE owner and history
journal. It does not claim a C81 package/store, an SDK page, native history
manager handles, revision tokens, CBB acceptance or rollback.

Only direct newly created textFields with unique single-component literal IDs
are supported, at most16 fields and64 ASCII bytes per ID. Those IDs are actual
caller parameters of native11D3C0. They are not generated recognition text or
C51 registry IDs. Paths, activeAreas, imported fields, prior results, layout
insertion, property events and external listeners are outside this factory.

All fields select the actual complete raw domain. Registry IDs advance by the
09EE20 automatic-ID branch after successful insertion. They do not use raw
object ordinals. Equal full-domain selections share one retained C22 range
identity across different registry IDs. Each entry retains its exact field and
INPUT node identities, name INPUT and category100 decimal. `ExportInputGeometry`
accepts only this owner's completed retained entry and resolves it through the
same actual current view. A failed prefix cannot authorize downstream work.

The DOM has one retained library BEE token owner. Equal names resolve to the
same typed token within that owner; tokens are not native addresses or Seed
names. The default namespace is a separate kind2 namespace domain with empty
prefix and the page URI, not an ordinary `xmlns` attribute. This scoped token
owner does not expose or claim the allocation order of all native CB7 names.

## Journal and failure boundaries

Engine BE2 observer10/18 uses0E0EF0/0E0FF0, records native kind1 and retains
parent18,node20,post-insertion previous28/next30. Attribute-insertion observer
30/38 uses0E12F0/0E13F0, records kind5 and retains parent/attribute. Detached
initial values are already in the retained inserted node. The C4D kind4
registration record retains actual name, assigned ID, a cloned/frozen copy of
the original C22 range value and category (0797F0/079A10). That history clone
and the C51-interned retained C22 have equal source bytes and the same original
source owner, but are different instances; the probe checks the distinction.
These payloads have typed library references; no native pointer bytes are made up.

The library journal retains completed mutations in their original order. It is
an explicit manager/storage adaptation, not the native global70/3D transaction
graph, command pruning algorithm or history persistence format. The independent
oracle reverses completed records on a separate value graph, checking each
stored sibling reference and removal of the exact registered ID. It does not
claim to execute native undo or restore its allocator/counter history.

Production creates a complete owner or a poisoned diagnostic prefix. Internal
prepared failure/cancellation checkpoints test each service boundary and retain
that prefix; no caller supplies a success flag. These checkpoints are library
fault controls, not simulations of every native low-memory outcome. In
particular native BE2's void observer allocation refusal can allow the enclosing
mutation to continue; this factory does not claim that its earlier-stop library
fault adaptation is that native branch. Native page-constructor disposal and
global history rollback are not replaced by invented rollback here.

Pre-entry cancellation leaves the owner reusable. Once entered, refusal or
cancellation poisons it and a retry fails. Historical state/value arrays are
private copies; failed state cannot be used by `ExportInputGeometry`. All
registry, history and source-event references retain the same original owner.
