# Owned fresh first recognition entry

`LegacyFreshFirstOwnedRecognition.Prepare` accepts resource/runtime data and raw
ink. The resource source offset identifies the already verified first247
model; there is no caller mask, acoustic cost, protocol flag, selected graph,
expected text or callback success result. It owns raw copies, first frame,
source chronology/probabilities,265 smoothing,297 cuts, native seed ordering,
resource graph cap/pruning, actual NN/final cache groups, derived protocol194,
regular+blank primary98 and the complete supported zero-trait B0/B8 passes.
`Run` selects the actual merged result and invokes native plain publication,
including its nullable word/leading-endpoint branch.

This is an owning first-stage entry. It still refuses unsupported traits,
aliases, interior multiword materialization or other resource profiles instead
of filtering their rows. It does not replace main240 or declare a final Russian
language winner. A first result such as mixed-script `MИP` is preserved.

## Checks and limitations

Four own printed/symbol fixtures exercise57 real NN/cache groups. Unified input
preserves the independently audited selections/costs41268,12111,14219,29007 and
correctly suppresses selected F0001 publication. The first literal outputs are
`MИP`, apostrophe, `O`, `III`; these are diagnostics, not Russian accuracy proofs.
Mask snapshots are independent copies. Reruns compare every selection field
except globally allocated context identities. Caller point mutation after
preparation and cancellation cannot change the owned invocation.

The independent Python oracle parses the pinned alphabet itself, checks its
virtual/header reconstruction and empty wide pair list, then validates masks,
cache widths, owning primary/B8 metadata and exact fixture outputs. The static
auditor reads PE/decompiled text only; no vendor DLL is executed.

```powershell
LegacyFirstOwnedRecognition.Probe AK.res engine-profile.json separation-profile.json captures.json
python tools/LegacyFirstOwnedRecognition.Probe/audit_output.py AK.res captures.json
python tools/handwriting/audit_fresh_first_acoustic_masks.py --resource AK.res --output static.json
```

An optional external-corpus JSON is metrics-only: expected text is never passed
to the owning algorithm, unsupported samples are recorded rather than omitted.
Actual handwriting corpus adaptation/pen-up fidelity and zero-word→main24A
fallback are separate work. No public GUI recognizer is enabled by this entry.
