## Runtime API and shared seams

The public production entry will accept only the typed completed English119
terminal and immutable explicit WORD120/glyph40 allocation storage. These
bytes are allocator boundaries; unwritten native fields are preserved rather
than assigned guessed zero values. Empty native pointer/vector constraints
are validated before mutation. No policy flags, labels, masks, success values,
delimiter results or expected text are caller inputs.

- `LegacyOwnedEnglish119PlainResultFactory`: actual model/source/terminal,
