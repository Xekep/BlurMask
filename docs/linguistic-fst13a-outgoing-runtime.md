# Owning13A outgoing primitive

`LegacyFst13AOutgoingSource` executes the bounded13A.V80 adjacency primitive proved in [the native proposal](linguistic-fst23c-outgoing-native-proposal-20261021.md). This is not28C query preparation, automatic language/source selection, alphabet conversion, recognition, string acceptance or an app integration. There are no old runtime edits.

The actual factory requires the exact retained Russian root and its existing raw23C child owner. Equal bytes in another root, a foreign child, or a generic raw reader do not acquire this source authority. It copies the bounded572,763-byte acoustic resource, hashes that private snapshot against the actual acoustic SHA, and reads sourceKind135 at5233 from that same snapshot. Caller memory is never reread after authentication; the full acoustic buffer is transient and is not retained by the result. The exact child envelope and root fingerprint authenticate serialized weight1 at child+100, version202,16-label alphabet and inline graph origin299576. No supplied JSON/calibration/string claim can replace these checks.

The sourceKind field is the stored acoustic kind, not concrete descriptor247. Its existing native provenance is documented in [the actual acoustic attachment](legacy-linguistic-mask-binding.md). Fresh constructor10A910 and initializer-list metadata, actual202 reader, sourceV50=10B3D0, all constants and callerV80=10BAC0 are pinned by the existing `linguistic-fst23c-outgoing-pins.json` and `linguistic-fst23c-wire-pins.json` proof packages. This API explicitly uses the fresh initialized source without property mutation: B8=1, serialized6C=1, source135 selects9C=1.5/AC=.15. It does not claim every configured/default SDK owner has this state.

The table owns256 int32 values indexed by signed TARGET descriptor byte6 plus128. It retains the special -128 and zero branches and each single-precision interpolation boundary. Separate non-inlined float operations prevent multiply/add fusion in Managed and NativeAOT. Full table digest is `6db9bc77ac744b8bb25b71d42d15f2ef088d9273b660b2950cb9bca788406ba3`. Generic caller-prepared tables are accepted only by the separately named diagnostic factory, copied before graph traversal and never marked as actual authority. An empty table selects the native null-cost branch; it is distinct from a256-element zero table.

The raw graph is already immutable, so the outgoing source retains that owner instead of duplicating it. Before publishing any source, the whole descriptor/word work budget is checked, every adjacent field0 is nondecreasing and within the complete word count, and every target word is below stateCount, including words preceding a nonzero first offset. This is an explicit stricter safe contract for malformed native data. Zero-state/zero-word storage is admitted but cannot be queried. The sentinel is never a queryable state. RawField20 remains opaque; neither its actual value12 nor any synthetic value is used as an initial state, row budget or graph validity criterion.

Query returns each exact adjacent-offset slice in original order, including duplicate targets and label0. Labels and byte7 come from the target descriptor. No sorting, deduplication, label fallback or source/target tag substitution occurs. OutputFlag is always0. The per-call row-work and16-byte-per-row payload budgets are checked before result allocation; the16-byte charge is the current value-struct storage size, excluding normal managed array/object headers. Whole graph work is capped at5,242,881 visits; row payload at64MiB; actual graphs are98states/299words. These are independent library limits, not invented native constants. Cancellation is checked before acquisition, during bounded copies/traversals and before publication. No asynchronous timing success is claimed by the deterministic pre-canceled controls.

Sources and results have no disposal API: immutable retained storage remains valid through ordinary managed lifetime. Result arrays are private, indexed rows are values and all array copies are defensive. Concurrent queries share immutable data only. Caller acoustic/root/table mutations, returned-array mutations and forcedGC cannot change the retained source. A raw storage origin receipt remains separate from outgoing authority; a diagnostic source built from actual raw bytes still exposes no actual root/child source authority.

Synthetic wide/narrow graphs cover signed tags -128/-127/0/1/127, labels0/255/65535, duplicates, empty rows, null costs, target byte7, arbitrary RawField20 and absolute origin3. Malformed graph offsets, sentinel mismatch, whole-graph invalid targets (including an unused prefix), foreign/equal-owner receipts, table/budget/index/cancellation boundaries, detached mutation, retained lifetime and concurrent reads are checked.
