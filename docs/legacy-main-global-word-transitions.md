# Owned global ordinary word-transition callbacks

`LegacyFreshMainGlobalWordTransitions.Prepare(AK, actualTransitionCache)` supplies
frontend118/140 and native ordered F0/F8 selectors for the same compact global
graph and its actual source descriptors. It does not manufacture a concrete
single-line graph, seed IDs, descriptor ordinals or source/context keys. The
selected cache owns the actual main0 resource, source guides and one CASE
symbol/query session. Existing single-descriptor APIs are unchanged.

This connects the previously restored [global transition cache](legacy-main-global-transition-cache.md)
to word-request consumers; [global group costs](legacy-main-global-group-costs.md)
supply the separate frontend128 class/prototype costs. It is not yet the full
2144F0 scheduler, winner, source publication or a handwriting-accuracy result.
The probe request packets are explicitly prepared controls over actual owned
raw-input graphs, not claimed scheduler output.

## Kind6 is a different request contract

`194170` writes graph190=1 and191=1 before copying main50=0 to192. Therefore
`1ACFA0` dispatches kind6 to samplerA0/`195650` **before** the main disabled pair
geometry short circuit. Kind6 Calculate118 is ordinary195C40 default success;
its140 callback performs the actual extra work.

For this kind only, packet04 is a **packed context key**, not a node ordinal.
`1A7CF0` sign-extends its24-bit node after shifting by7. The callback resolves
packet08/10 through the actual arc.EndContextId. `1AACD0` searches ordered paths
using `1AAA60` and compact selector1. It copies the first collected group bbox
to the result, then expands the subsequent stored group bboxes. ASM1AADE0,
1AADF3,1AAE03 and1AAE13 write the subsequent group memory, not the result bbox;
this surprising side effect is preserved in a private mutable geometry sidecar.
It is not replaced with a conventional union return value.

`195650` uses the current primary guide height, actual sampler weights0.5/5,
asymmetric15-fold distance terms, earlier-span overlap scan, signed nearest
rounding, cost addition and strict limit comparison. A missing path returns
false without changing the cost. No callback140 accumulator delta is invented.
Packet bytes are preserved. Calls are serialized. This sidecar currently serves
these transition callbacks; full shared native frontend-bound geometry lifetime
is a later controller integration requirement, not claimed by this class.

The portable path depth is capped at512 and traversal work at1,048,576 visits.
Invalid source keys, escaped row/selector indices and unrepresentable scalar
conversions fail explicitly. These are memory/work guards, not invented native
recognition decisions. Higher/opaque group kinds and unassigned descriptors
remain separate source policies.

## Verification

The probe starts eight actual raw-input source preparations, including multiple
descriptors/lines, pending separators, cross groups and the retained current
chronology. It captures10,620 full80 ordinary packets and1,254 actual-key kind6
callbacks. Inputs vary source-kind9, quotes/FFFD, earlier source vs ending refs,
near-overflow costs and limits; kind6 requests exercise101 actual bbox changes.
These are callback controls over genuine graphs, not corpus accuracy scores.
The independent Python interpreter reads actual AK labels and72 graph TCM ints,
first verifies the separate1941B0 capture, then checks every byte, status,
accumulator, scalar, kind6 path/overlap and final mutable bbox snapshot.
Cancellation/resource/unsupported-kind guards are checked independently of the
numerical success cases. Managed and Native AOT captures must be byte-identical.

Runtime probe arguments: AK, engine profile, separation profile, Unicode case,
publication data, line30, line50, output capture, LK.
