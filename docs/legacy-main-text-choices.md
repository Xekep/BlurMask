# Actual first-candidate text choices and original ink positions

`LegacyFreshMainTextGlyphChoices` connects an actual completed first main
candidate to source refresh, alternative selection, full273.V50 emission and
0213A0/021000 text-glyph publication. It retains separate WORDs and separate
alternative records. It does not expose a joined or accepted transcription,
enable automatic application replacement, or supply a guessed confidence.

The first024F30 loop refreshes every actual WORD reference before the second
loop selects and emits alternatives. Ordinary nonnegative owners use the
compact-driven217670 adapter and its actual source score services. Negative
owners use the owning span refresh without acoustic scoring, descriptor
append or an invented residual tail. Source positions and publication retain
their corresponding typed owners. The negative WORD-reference emission join
is implemented but has no selected negative reference in these seven fixtures;
the seven genuine negative pool owners are tested separately as source owners.

Emission uses `LegacyFreshMainGlyphUtf8Emission`, including the actual distinct
empty control2A and nonnull empty alternate owners. A kind4 failure cannot
silently become a primary-alphabet lookup. Full circled emission uses the
existing checked normalization/payload kernel. No successful circled winner
is claimed by this integration test. HeaderE filtering is false from the
fresh wrapper's zeroed local138.byte8 and absent prior-result property branch,
rather than knowledge99 or a caller switch. The exact producer is pinned in
[the global choice plan](legacy-global-text-glyph-choices-plan.md).

The string pool belongs to the publication owner. Disposing that owner makes
retained strings unreadable. The selected marker is carried through filtering;
an unavailable marker returns no selected bytes instead of selecting another
alternative. Each glyph snapshots only its canonical owner, avoiding a copy
of the entire pool for every glyph. Portable total budgets are4096 WORD
references,65536 published records and8MiB emitted UTF8. Publication is single
use, including after a failed mutation prefix.

## Raw source document

`LegacyFreshMainSingleLinePlainRecognition.Prepare` deep-copies the original
raw strokes before filtering or reordering. This library's indexed document
uses original caller stroke ordinals as source object IDs. Those are explicit
new root IDs, not inferred SDK page identities. Its actual closed whole-input
selection is expanded by `LegacyNativeSelectedInkProducer` into ordinary rows.

`LegacyNativeTextSourcePositionPublication` ports the fresh ordinary05AFA0
branches over those rows and one original closed collection interval. Positive
references traverse05AD80/053F90 and preserve source endpoint residuals. Final
end modes follow the original-range boundary and the terminal/degenerate
rules. Negative-span references use05A510 mode4 insertion positions, terminal
fraction0 and the native special single-reference object-boundary rule.

The native append operation is **Ink C21.V80=07FA50**, reached through context
20, table0E5AC0 initialized by001910. It appends ordered16-byte intervals after
checking first<=last. It does **not** union/coalesce them. The earlier roadmap
assumption that union was missing at this boundary was incorrect. C21.VA0 is
07FAE0/07F9A0; its range search normalizes fractionFF to0. Cached/C25 geometry,
multiple original collection ranges,024F30 source-node interning/reuse and
0283B0 final document assembly remain separate.

## Checks

The composed probe uses seven genuine raw invocations: a three-stroke word,
four two-word offsets, reversed physical input order, and repeated trailing
raw points. It checks26 selected glyphs,64 classified alternatives,52 selected
UTF8 bytes and seven actual negative source owners. Caller input mutation
after Prepare cannot alter the stored document or inference.35 entry,
single-use, malformed-storage and string-lifetime guards pass.14 failed-publication
retry checks and12 foreign ordinary/span-source checks also pass.

592 additional prepared source-position cases cover partial views, fractional
endpoint interpolation, quantized carry, ordinary end modes, one/two-record
insertion branches and independent source IDs7/11. The Python oracle reads
the raw AK alphabet and committed Unicode tables; no expected handwriting
labels enter inference. Managed and Native AOT captures are byte-identical
SHA256 `eb2c197d59781b75805cdcf029a84baf069f97fed0012978880bc219b730ebfc`.
Static audits pin four Text regions,40 exact instructions, three Ink regions
and the C21 descriptor/method bindings. Vendor DLLs are read only.

The probe arguments are AK,LK,engine profile,separation profile,case data,
publication data,normalization data,circled payload data,line30,line50,capture.
`audit_output.py` takes the capture. The optional static audit is
`tools/handwriting/audit_main_text_source_positions.py output.json`.
