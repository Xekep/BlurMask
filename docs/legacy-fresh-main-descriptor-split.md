## Exact descriptors and physical order

A singleton enters `15B260`'s initial one-physical branch: auxiliary field18 is
`02000002`, field4 is`INT_MIN`, field8 is the retained physical point count and
horizontal byte48 is true. With multiple physical strokes but one provider group,
field8 comes from the provider and is`?1`. The entire ingress physical order stays
unchanged in the one-provider-group case: native code does not sort that returned
membership vector there.

When there are G>1 groups, `1598E0` inserts2*(G?1) rows immediately after the
original descriptor and zeroes their newly allocated88-byte storage. Native group
order is preserved. Each group's physical IDs are sorted ascending by `0722C0`,
then appended to the physical permutation. Ordinary descriptors occupy ordinals
0,2,4,... and their24/28 fields address those current physical ranges. Field18 is
`02000003`; field4/8/horizontal receive the actual provider metadata. Only the
first ordinary descriptor keeps bit4 of its flags. Each next ordinary descriptor
starts as a complete copy of the preceding ordinary descriptor, preserving such
fields as the original submission's first X/Y rather than inventing per-row data.

The intermediate kind3 descriptors are real native records, not physical ink.
They have field18=`02000003`, field20/24=`?1`, float field28=`0.5`, field4=`INT_MIN`,
field8/10/14=`?1`; all other initially allocated bytes remain zero. They must not be
submitted to the ordinary graph as strokes. The portable snapshot exposes all88
bytes through copying methods; physical descriptor resolution skips the separators.

`16AA00` copies the source's28-byte physical metadata in this exact order and
copies each physical's point coordinates without interpolation. Probabilities are
permuted from the same source, never recomputed against reordered geometry. The
fresh source128 factor is200 (`16A130`); current points map to the original retained
global point ordinal multiplied by200. This preserves original raw physical and
raw point keys, including dropped duplicate runs. No source ordinal is silently
replaced by its new physical position.
