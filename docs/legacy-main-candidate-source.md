# Same-source completed candidate view

`LegacyOwnedMainCandidateSource` is an additive typed union of a completed
historical first candidate and a retained actual configured alternative. The
configured factory requires the genuine configured raw result, its active
alternative, selected2410 compact pool, same TOP, exact selected flush session
and complete callback list. It does not manufacture an old count1 RawResult.

SourceIdentity is shared by the alternatives from one actual raw invocation;
CandidateIdentity and selected Session remain different per279 list. InputOwner,
SourceDocument, Preprocessed, Sampled, SourcePolicy, ConfidenceOwner, actual
SourceOverlay and native WordHead18 are available through the common view.
Validation checks original input/preprocessing lineage, graph/dictionary/pool
ownership, successful callback order and the unchanged selected WORD head.
Historical RawResult/FirstCandidate getters explicitly refuse the configured
variant, and the configured getters refuse the historical variant.

The existing ordinary source26-byte export now has a named PrepareConfigured
path. Its numerical/key conversion kernel is unchanged. The old Prepare keeps
its count1 scope and explicit configured refusal; no synthetic original ranges
or source IDs are introduced. SourceOverlay comes from the real completed
flush session rather than a reconstructed empty geometry overlay.

`LegacyOwnedRawInkDocument.ProjectCandidate` invokes the existing05AFA0
ordinary position kernel using this exact selected metadata owner and raw root.
Foreign document or another alternative's metadata is rejected even when both
paths have the same model, graph, geometry or scalar label. The resulting
positions retain CandidateSource and SelectedSession. Their historical Result
getter is available for the original variant and explicitly throws for the
configured one. Existing Project overloads and their output are unchanged.

This stage does not widen the negative-span refresh, TextGlyphChoices or
TextSourceWrapper APIs. Those consumers still require their real typed
configured join; the existence of a common view is not that wrapper port.

The headless probe builds a genuine default raw first candidate and one genuine
configured raw result with two actual alternatives. It exports each selected
ordinary glyph's real metadata into its original six-point raw root (including
the duplicate input point removed later by preprocessing). The independent
Python oracle checks all packed positions from raw24-byte references, residual
bytes, float32 quantization and terminalFF. Twenty-one guards and explicit
identity checks cover cancellation, foreign result/alternative/document,
cross-alternative metadata, incorrect variant getters and the old named API.
The historical projection is compared directly to the same candidate-view path.

These are three source projections of one trajectory, not three recognition
samples or a transcript-quality score. Existing source-metadata/position static
auditors supply the native V140,26-byte layout and05AFA0 dependencies; this new
adapter adds ownership transport, not a new vendor numerical algorithm.

Managed and fresh Windows NativeAOT captures are byte-identical. The unchanged
historical metadata regression also passes in both runtimes:50 queries,31
higher sources,81 complete24-byte references,56 nonzero endpoint bytes and8
guards, independently checked against the actual graph/range/originalLast map.
