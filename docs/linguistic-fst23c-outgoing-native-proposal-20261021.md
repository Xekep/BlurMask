# Executable FST outgoing-query primitive proposal

This checkpoint proves a real missing executable primitive after raw23C storage. It does not implement full28C query preparation, lexical acceptance, number recognition or multilingual arbitration. No vendor code was executed, targets/expected strings were not used, and no app/default changes are proposed.

## Proposed NEW runtime phase, subject to review

Consume the parent's immutable raw23C owner; add NEW owning source/outgoing kernel and NEW probe/oracle only. No existing FIRST/MAIN/dictionary/app seams. Bind the actual number resource and139 source scalar provenance (whole source hash, exact child offset/end, version/flags/alphabet/weight), rather than accepting a caller-provided claim that an arbitrary array came from this native source. Retain an immutable owned raw graph snapshot plus the actual256-element default135 cost table. Whole-work validation before cloning/allocating output: stateCount+1 descriptors; nondecreasing field0 within declared transition count; each target <stateCount; complete signed-byte table domain; finite supported source parameters; configured memory/work/depth/cancellation limits. Reject an invalid graph before any query output. Last descriptor sentinel is not a queryable state. Invalid input refusal is an explicit stricter library contract, not native equivalence on malformed bytes.

Query(stateID) returns a detached immutable ordered result of targetState, sourceLabel16, int32Cost and target byte7; it always clears/records output flag0. Outgoing array length is derived from the actual adjacent field0 values; there is no compaction, sorting, deduplication, winner selection or string-label fallback. Per-call budget/cancellation precedes result copying, with cancellation during long copies and no borrowed array escape. Concurrent reads/disposal must have a documented snapshot lifetime and no in-flight array disposal; the simpler immutable no-disposal numeric kernel is acceptable if its raw-owner storage is independently retained. Arbitrary caller cost tables may be a separately named pure-kernel diagnostic API but must not acquire actual-resource authority.

Tests: all98 states/all299 ordered target/label/cost rows and complete256 table bytes, Managed/NativeAOT parity and independent literal Python oracle; negative comparison to unsigned-byte indexing and off-by-one centering, negative/positive extreme signed tags, absent table, duplicate arcs, empty/final rows and distinct alphabets/owners, malformed offset/target/sentinel/counts, budgets/cancellation, mutation/snapshot/disposal/concurrency, guards before allocations. Synthetic controls must be named synthetic and cannot count as handwriting accuracy. The native table's actual float constants are not tunable configuration. Existing raw23C storage and generic lexicon paths remain unchanged. Before any full28C/app join, independently close actual alphabet conversion, state0/special-label, history/paging/owner/default branches and automatic full-root source selection. This proposal transfers one executable primitive, not an application-ready recognizer.
