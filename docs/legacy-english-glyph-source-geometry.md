# English ordinary source geometry

`RunGraphFirstGlyphGeometry` is an explicit internal library path using the same owning English parent, source session, publisher and glyph pool as the glyph refresh path. It captures each original descriptor before its own refresh, projects the genuine count/fill records through a privately owned original raw document, and intersects those ranges with the same WORD source clip. Geometry exports are detached data. They do not issue CHAR, TEXT or admission.

The original raw-parent identity is retained throughout. External cached/prior/grouped source collections and nonordinary original descriptors remain outside this scope. Native order evidence pins complete 024F30 and dispatcher 13C6E0. General lazy-4000/repeated-reference callback state and postpass source processing remain open; repeated direct-refresh tests do not prove that state machine.
