# Recovered sampler297 marker geometry stages

`LegacyCursiveMarkerGeometry` restores three bounded, independently testable stages from the actual Russian continuous sampler297 path. Both sampler297 nodes of `models/ru-RU/ru_RU-ak-cur.lite.res` are version106, at offsets11506 and188157. This component takes already prepared point records and returns owned tag/marker arrays. It neither generates a complete native segmentation lattice nor recognizes cursive words by itself.

The vertical reversal branch in native `180191950` scans each physical stroke except its final point. A negative dy after a positive dy writes tag7. A positive dy after a negative dy writes tag8 only if the preceding segment's dx is positive. Zero dy retains the preceding direction. The first point and existing unrelated tags remain unchanged unless that exact branch writes them. This is one explicitly selected native branch; the full producer decides whether to run this branch from line geometry and runtime mode.

Native `1801911d0` prunes tags near pen lifts (tag1). The pruning radius is float32 `lineHeight * relativeRadius`, where the Russian serialized configuration has relativeRadius0.5. The point immediately before a pen lift and the final prepared point clear independently of distance, unless their tag is1. Walking farther backward and forward accumulates prepared segment lengths in float32 and clears only strictly below the radius; equality stops. Any tag1 stops a walk. The implementation scans the complete prepared point buffer; the native method also supports a restricted initial/end physical-stroke range, which is not exposed here.

The final projection in `180191950` emits nonzero tags except11 through14. It keeps source stroke index, local point index and tag kind in the existing point order. The unsigned comparison is preserved; tag meanings are not invented. `LegacyCursiveInkAtoms.Build` can turn these projected markers into overlapping endpoint ranges, and `Compose` can join a chosen atom path before `LegacyInkRangeExtraction` copies the original points.

The native producer additionally calls `18018e1f0`, `18018e960`, `180190350`, `180191430` and other geometry branches. They are not substituted with these three stages. The newer optional cut network at sampler state+138 is absent for Russian version106; the older serialized object at+40, read by `180010d80`, is a discrete category/mapping structure with geometry prototypes, not evidence of a seven-input neural network. No native SDK is loaded by these APIs or tests.

`tools/LegacyCursiveGeometry.Probe/reference_controls.py` creates1024 deterministic independent controls. The probe checks float32 accumulation, pen-up stops, equality, ordered projection, reversal gating, preservation of caller buffers, malformed bounds, cancellation and the4096-point cap. Both managed and Windows NativeAOT console runs are required before marking this stage ready. These checks establish branch arithmetic and ownership, not full native-engine parity or Russian handwriting accuracy.
