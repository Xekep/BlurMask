# Fresh first-controller source-to-cache session

This is the first, acoustic-only child249 path of the checked Russian source.
It consumes an **already selected row** and caller-provided candidate ranges,
kind, symbol mask and native pair list. It does not select a whole word, attach
a linguistic source, run the main class240 decoder or make Russian cursive
production-ready.

`LegacyFreshFirstGlyphSession.Prepare` joins original raw point ownership,
resource247/24a frame fitting and deskew,265 smoothing with factor200 point keys,
297 cut generation, first float context30 and247/229 acoustic feature networks.
`Score` obtains boundary signs from the chronology-ordered range view, then
constructs primitive scope using the graph's original range order and the actual
post-merge normalized stroke count, before final-cache195 production. The two
range orders are deliberately separate:1b4e40 sorts an index vector, whereas
1bb020 queries the graph's own ranges via virtual90.

The `LegacyFreshFirstControllerPolicy` is a data-only literal fresh policy. It
does not describe reusable/external source configurations. Raw scopeD8 is false
in this no-custom-source branch (16a130 initializes count148=0,167210 and16aa00
do not populate it), so the session does not inject source-scope penalties.

`LegacyFirstRowPrimitiveScope` owns the original raw physical counts. It builds
the end triple with `(nextRetainedRawOrdinal or rawCount)-1`, then applies the
same265/200 resampling and297 inserted-point mapping as the start chronology.
Its whole-scope predicate is exactly one normalized stroke, graph first range
starting0 and graph last range ending its physical prepared stroke. It reads
the source probability of that **first physical range**, without averaging.
The zero-endpoint predicate checks the raw ordinal field of the start and end
triples, not a geometry/class-category estimate. A repeated trailing raw dot
is therefore geometrically identical to a single dot but has a different end
ordinal and a false zero-endpoint predicate.

## Verification

`tools/LegacyFreshFirstSession.Probe` uses the vendor-free alphabet fixture
generated by `tools/LegacyAcousticCache.Probe/reference_controls.py`.512 varied
constructed source metadata records check each stored array index, mask bits,
threshold boundary and signed pen-up quotient; inactive gate, invalid cap,
owned range/frame propagation, cancellation before scoring and after callback,
null callback result and foreign cut ownership are covered. Six own printed
glyph fixtures verify original/duplicated-raw full cost vectors and equality
with the explicit prepared pipeline. Single and repeated raw point scopes
retain different ordinal intervals while using the same prepared geometry.

Managed and Windows Native AOT run both vendor-free and actual resource modes:

```powershell
python tools/LegacyAcousticCache.Probe/reference_controls.py controls.json
dotnet run --project tools/LegacyFreshFirstSession.Probe -c Release -- controls.json
dotnet run --project tools/LegacyFreshFirstSession.Probe -c Release -- controls.json models/ru-RU/ru_RU-ak-cur.lite.res models/ru-RU/legacy-engine-profile.json
```

Actual first-model cache at scale1 leads with Latin `M:6172`, Cyrillic
`И:16233` and Latin `p:14405` for own printed M/И/Р geometry; fallback costs
are73816,52501,49617. This exposes real model quality limitations instead of
adding a script/letter reranker. These six glyph diagnostics are not a
representative handwriting corpus or a claim that whole Russian words work.
