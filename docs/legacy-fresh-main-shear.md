## Physical metadata lineage

fresh direct source, without a prior source, recognized-input descriptors or
external property/callback events. `163970` initializes source9C to0.

The first-result driver `158970`'s prior-source reuse branch requires
secondary130, absent here. Its fresh `157C60` branch reads physical+4 to select
the submitted unknown interval; it publishes720 rows through secondaryC8 and
descriptor34/38. Child recognition receives its own source object. The

child-to-parent physical map, rather than the parent's physical-record owner.

typed stages retain physical association metadata. Thus the owning24D path
uses genuine association−1 for this lineage. A general reused/kind6/prior-source
owner is not accepted; the generic prepared helper requires its actual
association vector explicitly.

## Native numerical path

Text `1781E0` reads count bytes and five floats. Its angle conversion is the
double tangent (`250480`), rounded tofloat; the float tangent search interval is
divided by the radian step count. The actual38-byte24D/v100 node at188012 has
gap gate1..5, related floor0.3/normalizer0.9, angles ±π/4 and step π/180.

Text `177280` first sums `(rowCount−1)` over assigned ordinary descriptors.
It clamps the count blend and multiplies it by the weighted fraction of actual
AL-related first forms, with the stored floor/normalizer. Engine type2B's
virtual48 is `052B80`, the two cased-ID-range membership checks; it is not the
alphabet bitset predicate or a host Unicode classification. Virtual60 is
`052C00`, restored by `LegacyInkAlphabet.TryGetRelatedForms`.

For each float shear candidate, the algorithm transforms actual retained points
in every720 source range, tracks the maximum prior right frontier per
descriptor, and sums normalized gaps. It does not divide that sum by gap count;
strictly better scores replace the selected grid shear. Zero-range720 rows are
ignored in this search. Cross-physical ranges traverse the genuinely contiguous
retained domain, including intermediate physical buffers.

The second estimator uses physical segments whose association is−1, flips
negative vertical direction, rejects `dy <= float(1e−10)`, and restricts
`dx/dy` to the scaled search interval. Segment squared lengths use float
operations before double square root and double weighted accumulation. The
published shear is the float mean of the direction and gap-search estimates.
All descriptor points are sheared about their actual current guide baseline;
source720 boxes with real ranges are remeasured from those points. Zero-range
rows preserve their half extents while shifting their center. Guide geometry,
source labels, weights, ranges and remaining720 bytes are preserved.

The previous-source search narrowing/hysteresis branch is excluded by the
owning fresh type and absent from the generic no-previous-source helper. This
is not the general reused-source24D lifecycle.
