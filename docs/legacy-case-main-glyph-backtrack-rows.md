# Genuine CASE winners to numeric glyph rows

The additive `LegacyOwnedMainGlyphBacktrackRows.Prepare` overload accepts the
exact `LegacyFreshCaseMainSourcePolicy` retained by its actual CASE compact
materializer. It checks the controller, dictionary, model, sampled graph and
confidence/callback identities before entering the common numeric21FFD0 walk.
It neither constructs a DIRECT dictionary nor uses a caller-selected winner.
Equivalent independently created policies and the older DIRECT entry point
are refused for a CASE result.

The native append algorithm is unchanged: alternative-aware predecessor
walking, independently filtered lookahead, earlier-source carry, marker rules,
source keys and all72-byte writes use the existing audited implementation.
Fresh CASE source policy provides the same no-property/no-external ordinary
knowledge scope. This is not a case-conversion heuristic or a new selection
rule. The original DIRECT capture remains byte-identical with SHA256
`87ac86557c8477fa7cc714df85d37880dfe8fefe9d92209e5b46f8f0694c27b0`.

The headless probe performs128 stack-residue variations for each actual
materialized winner. The analytic four-node source produces256 complete rows
from1057 compact records. Optional pinned recorded tracks0 and6 produce384
rows each, from2112/eight-node and1835/seven-node compact owners. Together
these are384 actual walks,1024 complete rows and27 ownership/resource/cancel
guards. The Python oracle independently walks each entire captured compact
pool and compares all emitted72 bytes, padding, selected alternatives and
source-reference state. The existing native static audit remains applicable
because the numeric algorithm and its native source functions did not change.

Recorded tracks are opt-in private audit inputs. Their source dataset lacks
pen-up events; each track is explicitly treated as one unsegmented trajectory.
Expected transcriptions are never read by this probe. These runs verify a real
producer path, not Russian word accuracy, faithful recovered pen lifts or a
complete accepted transcript. Samples are not copied into the repository.

This remains **numeric append events, not complete21FFD0**. Word segmentation,
callback packets, residual association and accepted WORD/TOP publication are
separate. No caller-selected grouping or whole-word box is described as a
native recognized character boundary.
