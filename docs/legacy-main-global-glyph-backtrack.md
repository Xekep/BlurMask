`LegacyFreshMainGlobalGlyphBacktrackRows.Prepare(AK, materialization,
sourceCallbacks, stackResidue72)` consumes the actual selected global compact
pool and node offsets. It retains the same global policy, confidence and source
callback owners; foreign confidence, changed source epochs and other resources
are refused. No old concrete result or prepared selected compact index is
manufactured.

The shared `LegacyPreparedMainGlyphBacktrackRows` numerical kernel now serves
existing DIRECT, CASE and configured-secondary adapters as well. It implements
the ordinary `21FFD0` selected predecessor walk, independent filtered lookahead,
marker skipping, subtype0..3 key generation (`216610`), state carry and full72-byte
append events. Explicit stack residue survives in every unwritten padding byte.
Residual unit references remain a separate output. All public arrays are copied.

The initial frontend1A0 call uses the real global callback with cursor0. The
native early return (`1AAF67..1AAF73`) occurs before pending writes; actual fresh
pending controls have flagsC/D0, and the callback factory excludes unconsumed
trailing metadata. This does not imply that later protocol callbacks emit no
pending separators. No synthetic initial-row path is silently skipped.

controls. The independent raw compact/graph oracle reconstructs all 3,968 emitted
rows (285,696 bytes), visited indices, residual references and padding. Managed

`132f6f0e865b2f465828f1d2aea3c1190790743eac50e3b3df32df763783c2c2`.
No acoustic networks are reevaluated. Existing DIRECT/CASE/configured-secondary

This is numeric backtracking, not a complete `21FFD0` implementation. Actual
protocol glyph production, segment-boundary callbacks, residual association,

recognition remain separate work. The stated tests are algorithm checks; they do
not establish Russian cursive accuracy.
