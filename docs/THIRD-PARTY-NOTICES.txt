Embedded text fonts: Inter, Manrope, Source Serif 4, STIX Two Math and STIX Two Text
(regular and italic).

InkRecognition engine source is distributed under the repository MIT license.
Recognition model parameters are supplied separately and are not bundled with the app.
No MyScript DLL or Python runtime is shipped.

Formula inference uses the official native CPU ONNX Runtime 1.23.2 (MIT).
Its license, third-party notices and pinned archive hashes are included under
runtimes/<platform>/native/. Windows builds include the four app-local Microsoft
Visual C++ runtime dependencies from the builder's licensed Visual Studio REDIST.

Windows x64, Linux x64 and native macOS x64/arm64 builds include an independently
built Giac CLI (GPL-3.0-or-later), running as a separate process and disabled by
default. No Giac library is linked into BlurMask. The solver directory contains
complete license texts, component notices, provenance and the matching
source-archive SHA256. Corresponding source and the build recipe are supplied
in the same release as BlurMask-Giac-corresponding-sources-bdbb1c41.tar.gz
(Windows) or BlurMask-Giac-corresponding-sources-bdbb1c41-<RID>.tar.gz (POSIX).
See docs/agents/tooling/giac-runtime-build.md for pinned sources and build details.
