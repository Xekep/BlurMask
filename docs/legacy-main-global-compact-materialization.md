# Actual global compact publication

`LegacyFreshMainGlobalCompactWordMaterialization.Materialize(AK, terminal,
confidence, allocatorResidue40)` connects the real shared global graph's selected
terminal to ordinary `207CB0` publication. It retains the producing pass's
post-final-V80 query lease, actual symbol/context factory, category profile,
language penalty and cached candidate weights. It constructs neither an old
same-source pass nor replacement acoustic outputs.

`LegacyPreparedMainCompactPublication` now contains the numerical algorithm
shared by the existing DIRECT/CASE/configured/live adapters and this global
adapter. Typed adapters continue to validate their original owners. The shared
algorithm marks paths through the existing reachability owner, orders and
coalesces primary alternatives, evaluates the raw dictionary continuation gate,
normalizes context frames, appends real compact40 records, updates beam22 and
primary-pool1C indices, and emits the used-arc candidate headers. All input
allocator residue is explicit; no native allocation address or zero-allocation
policy is invented. Failure after publication entry consumes the pass's lease.
The returned pool, indices and all three node buffers are copied on public reads.

The supported global route is fresh mode0, primary2/secondary1, two headers,
ordinary kind0 groups, EC0, no associated source or trace, and at most the actual
120-node intermediate-publication boundary. Reachable unsupported protocol,
forced-marker, secondary or source-expansion branches retain explicit refusals.
Global sources beyond the boundary still require a persistent live publication
owner. This stage does not implement global `21FFD0` glyph reconstruction,
`275` WORD publication, document acceptance or application selection.

The eight actual global inputs contain 110 nodes and 12,045 real compact records.
The probe compares snapshots, validates pre-entry resource/cancellation/shape
checks and single-use publication, and verifies unchanged acoustic evaluation
counts. An independent Python oracle reads the packed AK/LK resources and
reconstructs all 1,310,720 compact allocator bytes and 2,610,080 beam/pool bytes,
including unused residue. It does not compare expected text or accept production
C# output as its expected numerical result. Managed and fresh Windows Native AOT
captures have SHA256
`04baac6abb1c4c0136428ccea3e1addf86dc64595a2f9831975e6d333f45677a`.
Existing DIRECT compact, live/final append and configured-secondary reachability
checks pass after extraction. These checks demonstrate algorithm parity on the
stated branches, not improved Russian recognition accuracy.

Static provenance remains in `tools/handwriting/audit_main_compact_materialization.py`
and `audit_main_live_compact_publication.py`: pinned binary ranges and exact
instructions are read without loading or running vendor code.
