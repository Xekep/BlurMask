# Line-aware global main transition caches

`LegacyFreshMainGlobalTransitionCache.Prepare` builds1941B0 cache rows on the same
actual compact graph and case-source owner. It retains each group's primary
descriptor ID, resolved line ID, actual guide height and bounds. It consumes
the source's actual gap and the main297 resource profile. It does not convert
descriptor IDs into physical or document-object IDs.

The reverse future-minimum fold follows compact selector1 in native order.
The forward prefix-maximum fold follows selector0. Both folds compare the
resolved primary **line IDs** of adjacent groups. Different descriptors sharing
a line are not filtered merely because their descriptor IDs differ. A missing
matching predecessor falls back to the current maximum X. Root-span cache rows
retain impossible costs and their own prefix maximum.

The current primary guide height divides the transition gap. This differs from
the union height used by1B4E40 normalization and193860 group geometry. Join,
triple-gap, blank and36 category-matrix channels preserve their existing native
rounding/caps and last-row minus-one/last-column behavior. The actual main profile
has10C disabled, so the blank field uses minimum X. The version106 resource and
fresh constructor/clone/init path prove242 disabled and no extra1D0 boundary
network. This owner explicitly supports assigned ordinary descriptors; it does
not widen configured, opaque or unassigned-source policies.

The returned state owns a copy of its matrix. The checked separation table is
also copied before use. Public diagnostic memory cannot alter the retained cache.

Eight actual raw owning inputs produce631 arc caches, including five cross-source
groups. On actual one-descriptor domains472 arc comparisons match the existing
owning transition and blank caches. Python recomputes all point-derived bounds,
both line-filtered folds, primary-height gaps and39 integer channels independently.
There are129 genuine rows whose folds/costs differ when line filtering is removed.
Forty guards cover foreign resources, invalid ordinals and cancellation; public
matrix recovery is tested directly. Static proof pins15 instructions and the
whole1941B0 PE block plus the fresh version106 no242/no1D0 chain.
