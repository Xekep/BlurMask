## Smallest owning API

`LegacyOwnedEnglish119Terminal.Select(completedContext, token)` retains the
exact completed context, primary, policy and cache. It builds the existing
immutable merged grid using A4=1 and the actual source BA/F8, derives the
scoped invocation fields above, calls `LegacyFirstTerminalSelection`, and
calls `LegacyFirstSelectedGlyphTrace` for each actual choice. Public records
and traces are detached/read-only. Cancellation publishes no partial result.
The stage performs no acoustic evaluation and checks that the retained
cache lifecycle is unchanged in its probe.

Native relative cost, mass and normalized acoustic score are separate
channels. `Math.Exp` remains the existing portable transcendental adaptation;
no universal bit-exact CPU exp claim is added. The result is a FIRST numeric
winner/trace, not a linguistic dictionary winner or recognition confidence.
No model's labels are coerced into a Russian factory/alphabet.
