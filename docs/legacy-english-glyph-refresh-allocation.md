# Scoped glyph refresh/selection/UTF8 logical ledger

This is a conservative managed logical payload/copy reservation, not CLR allocation bytes, RSS, JIT/GC work, or a whole-transitive CPU certificate. All original operation gates/caps remain unchanged. Reservations are cumulative and never refunded on deduplication, callback failure or later refusal.

Before retaining the same-source range receipt: allocate4096. Before refresh count/fill or pool changes, walk all actual WORD references (1..128), authenticate same stage, direct arc, canonical owner key and scalar existing owner count. No snapshot becomes an issuer. New count accessor returns ONLY private `node.Rows.Count`; it allocates no arrays/collections and exposes no owner.

For each reference, let C be that logical node's complete compact interval count; r is the number of actual references with this canonical key; O is the current existing private owner count; M=min(2040,O+r*C). Repeated canonical keys execute EVERY count/fill/cache/score/refresh; an ordered list retains that reference's own Source26/first-score/visited values. After ALL refreshes, selection snapshots the live final owner. UTF8 rechecks that current owner bytes equal that selection's owner image. Diagnostic DATA is never source authority.
