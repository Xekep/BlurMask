## Portable resource contract

The caller supplies `LegacyMainGlobalRepeatedPublicationBudget`:

- `MaximumLogicalNodes`,1..50000. The upper envelope matches native214826/21482D;
  it is not a claim that every input of that size fits other restored stages.
- `MaximumRequestedControllerBytes`,1..1GiB. This counts **every requested
  allocator payload**, including replacement/growth requests, cumulatively.
  Remaining budget is checked by subtraction before addition or calling the
  external allocator. It is not a retained-heap or RSS measurement.
- `MaximumCompactStorageBytes`,40..64MiB. This bounds the supplied fixed compact
  pool. Complete40-byte records and its existing numeric capacity checks remain
  mandatory. Defensive snapshots have bounded copies; observer-retained copies,
  preprocessing/graphs/model storage and runtime overhead are not charged to the
  controller allocation counter. This is not a whole-process memory budget.

Source/count/storage preflight rejects before controller allocation or main group
NN evaluation. The raw route checks its node cap as soon as the graph exists,
before creating its global227 context. Preprocessing may already have evaluated its own first-stage
models before the global node count is known. Malformed/canceled raw entry and
compact-budget preflight do not consume the raw invocation. Later failures
consume it. A started controller pass is single-use, including budget exhaustion,
cancellation and observer exceptions. Already completed LIVE snapshots remain
detached and visible; the native numeric prefix is not rolled back.

The wrapper accepts no supplied success flag or terminal. A typed repeated
result is validated against its exact producing owner before final append.
The old final API still refuses a long result; callers must use the named
repeated path. Unsupported associated/custom source, protocol and physical-ring
branches retain their existing refusals.
