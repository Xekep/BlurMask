label/target/model change. Existing separation, first-primary and global-group
regressions are rerun; raw candidate and confidence computations are unchanged.

`ScoreGroup` reuses the existing actual cache, raw two-family results and
confidence instance. A completed result is cached once; all public arrays are
copies. Failed/canceled requests never install a new controller-group result.
Earlier successful NN/cache prefixes can remain in their existing owners.
No acceptance threshold or confidence clamp is added. A query's symbol,
shortlist ordinal, signed prototype index, primitive and top20 flags are
explicit downstream inputs; tests do not assert that a native scheduler issued
every supplied request. Finite checked integer arithmetic and the existing
source's bounded graph/point limits remain portable refusal boundaries.
