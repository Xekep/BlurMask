# Owning outgoing Math transfer

`Math2Mode0OutgoingTransfer.Create(actualCompletedPublisher)` produces one
owning library outgoing DOM edit and detached source-command list. The input
must be the genuine completed fresh Math publisher with its actual original,
selected and third registry identities. No caller supplies a result tree,
expected text, command IDs, source ranges, successful receipt or selected field.
The original PAGE and Ink are not mutated. Native CBB/revision/page acceptance,
combined source/DOM rollback and application-engine switching remain separate.

The sole old change is a trusted completed-publisher accessor. It validates
the receipt before entering the field gate, then uses the actual field accessor
to validate the pre-NN binding, retained first copy and selected INPUT. Under
field → publisher gates it checks completion/liveness and supplies borrowed
readonly views. The outgoing operation enters its own gate after those gates.
No receipt gate is acquired inside the field or publisher gate. Result reads
recheck the exact retained original/selected/third objects and actual field ID.
Closing the publisher, receipt or field invalidates new operations. Disposing
the outgoing owner never disposes those borrowed owners or the first-copy pool.
The independently owned fourth-writer payload and detached commands remain
inspectable through historical `CopySnapshot()` after publisher disposal; the
probe compares that entire snapshot before/after disposal. `CopyResult()` is
intentionally stricter library authority: it requires a live source/publisher
even though the outgoing storage is independent. This does not claim the same
post-release API behavior as the native exported edit. Retaining the publisher
for authority also does not claim that its managed diagnostic tree was collected.

The kernel verifies the selected id attribute and complete INPUT subtree against
their actual temporary clones. Its outgoing edit is one operation2 at empty
field-relative path, ordinal derived from the preserved selected children (1).
The earlier three temporary actions are not reused as this new edit. A fourth
DOM name owner and arena own a fresh deep clone of the completed mathResult,
visiting attributes before children and retaining each temporary source-node ID.
The payload remains unattached to the transport arena's generic root. Typed
values, namespace declarations, strings, FLOAT32 positive0, INT32/INT64 values
and all rewritten tags are preserved. Names are explicitly interned into the
fourth library name pool; immutable strings are shared. This is semantic library
ownership, not a native pointer/allocator image.

Selected INPUT remains unchanged. New actual category102 registry entries are
exported in ascending signed-ID order, as established by the native set service.
Each operation4 owns a detached copy of the actual C22 ranges, its exact ID/name/
category and no auxiliary. The operation7 uses actual selected Next and third
Next; neither is derived from symbol count or a fabricated initial counter.
The kernel checks the complete contiguous ID set, original INPUT equality,
all result INT64 tags and range containment in the retained INPUT. Child lists
are indexed once; payload traversal does not repeatedly scan the full tree.

Before any payload/name/C22 clone or one-use claim, the kernel checks cancellation,
complete graph/count/depth/value/range/counter bounds and the whole conservative
retained envelope. Borrowed metadata records are inspected during preflight;
payload/name/range copies start after it. Limits are65536 nodes/registry entries,
depth256,32MiB typed-value/name bytes and64MiB logical envelope including the
existing publisher reservation. These are logical retained-storage bounds,
not process RSS measurements. An exact-budget refusal is reusable.

A CWT tied to the actual produced publisher arbitrates one successful factory
claim, including concurrent factories. Entered throw/cancel failures poison that
new lifetime and retain completed allocation/export/handoff prefixes for audit.
Preentry cancellation/budget refusal does not consume the publisher. Immutable
inspection snapshots deep-copy mutable arrays. Owned semantic resources have
one cleanup transition; snapshots preserve their managed diagnostic representation
after disposal. The successful owning handoff is explicit and checked. Native
028070's ignored C8F append refusal and leaked prior edit after later failure
remain static evidence; this library does not return false success or imitate
those leaks. Logical failure injection is not a native allocator-ABI equivalence.

The probe uses the existing test friend assembly name in a separate project
directory, so no second old assembly-access seam is introduced. Six real NN
outputs cover production cold width1 and physical reversal, plus diagnostic
prepared-search widths3/16 and their reversals. Wider prepared search is not
claimed as fresh native width selection. A tracked independent Python oracle
reconstructs numerical/raw AL/C79/C21 metadata, the full temporary publication,
then independently clones the complete outgoing typed tree and command list.
It validates every source-node map, range, ID, counter and all64 logical failure
prefixes, plus168 guards, exact budget and concurrent one-use claims.
