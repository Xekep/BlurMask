# Fresh first-source glyph confidence

`LegacyFirstOrdinaryGlyphScoreProducer` connects actual first-source neural
probability channels to the scalar confidence that1BCBD0 writes into a retained
candidate's vector10[0]. It does not exponentiate the candidate cost or reuse
the score of the whole word.

The loader owns a validated first247 source/model. Its strict model reader
requires one nongrid profile, two active EXP families, absent other families
and no dynamic converter. The inline alphabet's header8 must exist; otherwise
the native getter selects a separate log-score branch. Fresh metadata and
150D00 derive packet byte19 from frontendFlags bit11.1B0760 forwards that byte
to runtime1A8; the supported policy requires it false. The literal cache tail
must contain obsolete-conversion flag0 and calibration mode108=0. First-model
scores carry a SHA256 fingerprint of their complete owned source node, so a
foreign source with equal network widths cannot feed this producer.

For a retained native output label,1BCBD0 calls the active network's D8 getter
with label+1. EXP object table2BA2C0 slotD8 is0EBD30: it converts the quantized
probability to float with factor1/32768. Default13E8E0 has no coefficient table
and uses center0, **double0.575**, then logistic calibration. The two calibrated
float channels are added in native order family1+family0, followed by five
absent zero families, then divided by2. Candidates at indices20 and above
receive zero. The native normalized candidate24 field0 remains a separate
channel calculated later by1BE530.

The first family's output-label namespace is preserved. Primitive or alias
labels outside the network width require their actual confidence mapping and
are explicitly refused when retained, rather than assigned guessed scores.
This is the fresh unmodified source branch; cloned sources, external alias
overrides, mode1/2 calibration tables and individual-network channels are not
silently accepted. Candidate order remains an explicit output of the owning
final-cache producer.

The headless probe uses72 raw-source groups with actual frame fitting,
smoothing, context selection, trajectory/raster networks and final caches.
Original three glyph drawings receive varied scale, translation and point
perturbations; they are diagnostics rather than labeled cursive accuracy data.
It captures12,960 scores alongside their actual neural channels and candidate
order. A separate Python oracle checks every score bit; four values distinguish
double0.575 from the unrelated stored-float-slope branch. Foreign-source,
nondefault-mode, empty-group and cancellation checks also run. Managed and
NativeAOT execute the same path without loading vendor DLLs.

This stage supplies the real native-output scalar channel to the prepared
glyph-score cache. Complete rich273 winner assembly, native alternative
mapping and main linguistic search remain integration boundaries. It does
not enable Russian recognition in the application or claim word accuracy.
