# Math original-source sampler13A2

The library contains a private fresh scalar Math13A2 sampler and a headless diagnostic tool. The tool creates an authenticated feature profile and follows the same fresh original-frame/bootstrap/13B6/13A0 context before invoking the sampler while that context is still live. It exports detached numerical DATA. Historical13A0 factories, public recognition defaults and user routes are unchanged.

This is a finite fresh, unknown-baseline subset of the actual Math297/108 scalar program. It runs both configured horizontal passes, keeps the stored one-anchor policy, preserves nongated baseline loop-exit logic, composes original point maps and emits native-style shared-endpoint ranges. Stored policy is read once from the same authenticated profile; it adds48 logical scalar bytes to every profile. There are no per-subset weight/calibration/resource clones or new neural calls.

The context/claim/frame cannot be recovered from the detached arrays. Neither these arrays nor the standalone diagnostic grant processed-graph, FIRST3F276,13A4 matcher-request or formula-candidate authority. Graph construction and the genuine first-vector/terminal/grammar join remain separate work. Completed historical contexts cannot be resumed through this route.

## Operational limits

Existing13A0 has its own32MiB source-site reservation. Sampler13A2 adds128MiB cumulative logical payload and1,000,000,000 loop/copy units. It can transparently refuse a source previously admitted by13A0; it does not truncate, raise old caps or promise all possible upstream shapes. Diagnostic export separately enforces64MiB logical payload and64Mi loop/copy units before its nine array allocations. Its byte formula is256+12*Qbefore+12*Qafter+24*M+32*S; its work formula is6*Qbefore+6*Qafter+12*M+12*S. The old512-byte scalar observer is not reused. Probe-retained detached DATA is capped at128MiB.

These are explicit operational/source-site limits, not native constants, process RSS, a retained-peak estimate, CPU instruction counts or latency guarantees. Repeated private whole-buffer copying remains a performance limitation. Added profile storage is an earlier separate cost. Any entered failure poisons the same consumed context; no clean retry or transactional native-failure-prefix equivalence is claimed.

A strict-monotone-X fast path skips only segment pairs whose closed X intervals are necessarily disjoint. Equal X, reversal and other rows retain the original intersection path. It adds a charged/cancelled scan without arrays. The proof concerns successful numeric output, not native instruction order or cancellation/failure-prefix identity.
