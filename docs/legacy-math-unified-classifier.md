# Fixed selected-five Math AL numerical classifier

`LegacyMathAkUnifiedClassifier` connects the five restored base-tail Math model kernels to the native unmasked cost combination,13A6 prototype adjustment and262-slot sort/prune/top20 projection. It takes an existing authenticated `LegacyMathAkSelectedModels` and source created from that model owner's exact `FeatureProfile`. It supports one whole stroke with2..255 original points, absent guide and the fresh all-label numerical branch. It accepts no caller cost/probability vectors, grammar mask or predicted labels.

The classifier prepares1F222/2F204 and the shared3F279/4F279/5F223 bundle. Each `Evaluate` runs the five fixed models without cloning their weights or recalibrating the resource. The optional299 producer is lazy: a finite best label with positive prototype alternatives calls it once; one alternative still produces geometry but skips distance calculation. Zero alternatives does not add a299 failure or allocation. Every call owns its scratch/result arrays; public outputs are defensive copies. A cancelled or unsupported calculation publishes no result. Some unsupported numeric/299 branches are discovered after network work, matching the selected call order; this is not fail-before-forward admission.

Integer costs are not confidence. `Confidence` is null and `HasGrammarCandidateAuthority` is false. The259 stored AL namespace,257 network rows and262 native scratch slots are distinct. Virtual256 is forced impossible; quote scratch260 can consume a top20 position. Apostrophe107 is copied there. Runtime alias152 is absent U+F0001, while lowercase o70 is alias154 and remains a normal label. Output rank order preserves the native unstable tie policy and is not recomputed after pruning.

This primitive does not implement13A4 requested subset masks/cache, grammar matching, terminal ownership, candidate trees or complete ink recognition. It supplies no application default routing or handwriting accuracy claim. Existing five per-network kernels retain their documented modular arithmetic and unsupported INT_MIN/dynamic-range cases.
