Historical constructor PAGE snapshots remain readable. The new active PAGE
overlay and source/journal diagnostics are named separately from that history.
No new native C4D/Base70 objects or recovered SDK revision are synthesized.

Only two old seams are proposed:

1. A completed outgoing trusted application accessor, validating live authority

   exact original Ink identity with that actual field source. It supplies actual

   Returned ID/C22 identity is checked, including equal-range interning against
