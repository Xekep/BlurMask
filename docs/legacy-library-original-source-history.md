`LegacyLibraryOriginalSourceHistory.Prepare(actualOriginalBootstrap)` retains
one successful original PAGE/INPUT/C51 bootstrap. Its `CreateSelectedInput`
issues the exact existing selected context before the publication scope and
neural execution are constructed. The same original is retained by the new
owner and the bootstrap's `SourceHistory` property; no post-inference Seed,
source registry or binding replacement occurs.

This is an explicitly library-owned one-depth source-history adaptation.
Managed containers and typed retained C22 values represent registry membership
and the generated source frame. They are not native Base70 objects, pointers,
AVL/hash allocation images or a general history manager. The original
bootstrap's `State` and initial journal remain immutable and historical;
`history.ActiveState` is the separately named active original registry view.
The original PAGE tree is not rewritten by this source-only operation.
