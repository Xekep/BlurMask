# Configured negative-span source, insertion positions and glyph emission

This joins the already transferred fresh ordinary source/TOP operations to a
genuine selected configured alternative. The configured path retains its actual
2410 terminal/session, candidate-local overlay, shared TOP/glyph pool and raw
root document. It does not construct a count1 result or widen the historical
`Prepare(rawResult, ...)` getters.

## Owning API and native scope

- `LegacyOwnedMainSpanGlyphSource.PrepareConfigured(candidate)` snapshots the
  actual one-descriptor graph/ranges and original point metadata. Its `Read`
  operation validates the still-completed candidate and retains the existing
  ordinary reverse `1A9AE0` branch. The negative signed arc, low24 last context
  and bit56 mode remain distinct from an acoustic group or a symbol.
- `LegacyOwnedMainSpanGlyphRefresh.PrepareConfigured(candidate)` keys mutable
  refresh state by the actual selected alternative. Repeated views of that
  same candidate use the same epoch; distinct candidates keep different
  overlay/ownership state. Refresh requires an existing actual canonical
  negative-span pool owner, exports 24-byte references without a residual tail,
  sets native `217670` scalar1, and never appends or scores glyphs.
- `SourceDocument.ProjectSpanCandidate(candidate, source)` accepts the same
  actual candidate identity, selected overlay/session and original document.
  It calls the existing `05AFA0` insertion kernel (mode4, terminal fraction0).
  It does not convert a negative insertion source into an ordinary closed
  glyph interval. A new view object for the identical candidate remains valid.
- `LegacyFreshMainGlyphUtf8Emission.PrepareConfigured(candidate, normalization,
  circles)` retains the shared actual TOP/primary alphabet. Fresh source
  170/180 alternate vectors and lookup-only control2A stay empty. `273.V50`
  passes a nonnull empty alternate owner; kind4 consequently retains the
  native refusal instead of using the primary alphabet fallback.

The only supported preconstruction main property is short18=2, whose writer
`00D83A` cannot populate source alternate vectors, protocol contexts or control
2A. Static dependencies pin that property, the fresh constructor/reset
lineage, the native negative source and C21 position paths, and TOP.V50. No
vendor DLL is executed by the audit.

`SourceIdentity` identifies the common raw invocation, not a mutable refresh
cache or a selected higher-source namespace. Configured ordinary higher-source
refresh remains explicitly refused by the preceding batch. This extension
makes no claim that candidate-local higher source IDs can be interchanged.

## Evidence

The new probe uses three real configured raw inferences: one duplicated-point
M trajectory, a six-physical-stroke input, and its reversed physical ordering.
It does not read expected transcriptions or change inferred labels.

Each Managed and Windows Native AOT run covers:

- 46 actual current shared-pool record emissions, independently checked against
  raw AK labels, native run counts and the empty control/alternate decisions;
- six negative-span owners actually present in inferred pools, with unchanged
  complete record bytes/count flags after refresh;
- 4,256 explicitly prepared negative-span requests over the actual owned source
  graph and 4,064 bounded refusals, covering both modes/all six resolver branches;
- 7,020 insertion position outputs, independently mapped to original raw object
  IDs, including the filtered duplicate's distinct ending metadata;
- three overlap controls: A refreshes a genuine base key, then B refreshes the
  **same** base key in the same TOP. Both source allocations/scalars and every
  shared-pool record/count flag remain identical (1,160 bytes compared);
- 12,880 cancellation, incorrect-variant, altered-record and foreign-candidate
  projection guards. The many guards repeat on each prepared source export;
  this is not a count of distinct recognition inputs.

The prepared requests are explicitly separate from the six inferred span
owners. Full existing span and emission probes remain unchanged: six raw
sources/six actual negative owners/5,452 prepared exports/5,210 refusals/72 guards;
14 actual emission rows/1,656 prepared descriptors/263 bounded refusals/four
emission guards. The historical ordinary candidate/document projection probe
also remains unchanged.
