# Границы проверок

Проверка должна соответствовать изменённой ответственности. Компиляция подтверждает типы и связность, headless-контроль — заданные контракты, реальный рабочий стол — поведение native окон. Эти уровни не заменяют друг друга.

Для обычной проверки сборки из корня репозитория:

```powershell
dotnet restore
dotnet build -c Release -p:PublishAot=false -p:SelfContained=false
```

CLI-режимы перечислены в [`Program.cs`](../../src/NovaPen/Program.cs). `--ai-pen-test` запускает набор headless-проверок, включая `DesktopFeatureChecks`; `--overlay-platform-test` включает `MaskAttachmentChecks`. Математические проверки требуют соответствующего model/runtime-пакета; `--math-solver-test` проверяет реальный Giac и его маршрутизацию. Запускать нужно собранное приложение с ожидаемыми зависимостями, а не произвольную старую копию.

| Изменение | Что проверять |
|---|---|
| Документ и инструменты | Группировку операций, отмену, временные штрихи, преобразования и сохранение |
| Выбор окна | Быстрые переходы между целями, исчезновение цели, исключение собственных окон, совпадение preview/confirm |
| Native interop | Реальные дочерние окна, перекрытие, сворачивание, смену монитора и DPI на целевой ОС |
| Решатель | Включённый/выключенный путь, синтаксис, реальные ответы Giac, отмену и завершение процесса |
| Синхронизация | Повторную операцию, права edit/view, восстановление ревизии и ожидающие локальные изменения |
| Упаковка | Полную publish-папку, native loader, установку, обновление, удаление и соответствующие лицензии |

Desktop smoke-режимы требуют графической сессии. Их запуск в headless-среде не даёт доказательства поведения интерфейса. Рецепты и CI-команды — в [справочнике сборки](build-and-packaging.md), правила участия — в [CONTRIBUTING](../../CONTRIBUTING.md).

Для восстановления движка нужны независимый ожидаемый результат, происхождение входа и сохранённая первая ошибка. Синтетический helper-тест не доказывает работу настоящего владельца, качество OCR или готовность AUTO-маршрута. Такие протоколы хранятся в [разделе агентов](../agents/README.md).
