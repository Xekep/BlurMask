# Конфигурация и применение настроек

[`AppSettings`](../../src/BlurMask/AppSettings.cs) задаёт сериализуемые параметры и значения по умолчанию. [`SettingsWindow`](../../src/BlurMask/SettingsWindow.cs) редактирует рабочую копию; применение передаёт изменения приложению. UI настроек не должен самостоятельно менять алгоритмы распознавания или запускать обходной вычислитель.

| Настройка | Контракт применения |
|---|---|
| Язык | Системный язык по умолчанию; изменение применяется после перезапуска |
| Сочетания клавиш | Применяются сразу; дубликаты отклоняются, во время записи обработка приостановлена |
| `GiacEnabled` | Новое значение по умолчанию — true; явный сохранённый false сохраняется, при выключении вычисления не выполняются |

Параметры хранятся в локальном каталоге данных пользователя: `BlurMask/settings.json`. Состояние отдельной доски хранится отдельно в `BlurMask/canvas.json`; история отмены и экранные пометки относятся к сеансу. Настройки не являются каналом отправки рисунков на сервер.

Значения по умолчанию нельзя применять поверх явно сохранённого выбора при обновлении. Платформенные ограничения глобальных клавиш и окон задаются backend, а не обходятся в диалоге настроек. При добавлении параметра проверяйте загрузку старого файла, сохранение выбранного значения и поведение реального потребителя.

Связанные контракты: [Giac](math-runtime.md), [платформы](platforms.md), [рисование](drawing-and-document.md).
