# Граница математического runtime

[`AiMathSolver`](../../src/BlurMask/AiMathSolver.cs) — адаптер приложения: читает настройку Giac, выбирает исполняемый файл и передаёт принятый запрос. [`SymbolicMathSolver`](../../src/InkMath.Solver/SymbolicMathSolver.cs) — независимая библиотека: разбирает разрешённый LaTeX, формирует CAS-запрос, запускает Giac CLI, ограничивает процесс и нормализует ответ.

`InkMath.Solver` не зависит от Avalonia, моделей распознавания и сервера. Все вычисления, включая простую арифметику, выполняет Giac. При выключенном, недоступном или неуспешном Giac встроенного запасного калькулятора нет.

Запрос возникает явно: завершающий `=` после выражения, дополнительный `=` после готового уравнения или действие вычисления над выделением. Уже записанная правая часть не является разрешением автоматически переписать уравнение. Сомнительный OCR-кандидат не должен запускать решатель.

Каждый запрос выполняется в отдельном временном каталоге без shell-интерпретации. Процесс получает ограниченный ввод; вывод и время ограничены, отмена распространяется на процесс и очистку. Поддерживаемый синтаксис намеренно уже произвольного языка Giac: приложение не предоставляет общий интерфейс выполнения CAS-кода.

`GiacEnabled` включён по умолчанию для новых настроек; ранее сохранённое значение сохраняется. Успешный результат участвует в undo/redo и обычной синхронизации доски. Отказ оставляет исходную формулу доступной для редактирования.

Подробный синтаксис, протокол, лимиты и проверки: [solver reference](reference/math-solver.md). Происхождение native runtime и воспроизводимые рецепты сборки: [Giac tooling](../agents/tooling/giac-runtime-build.md).
