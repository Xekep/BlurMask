# Платформы и поставка runtime

Desktop-приложение использует Avalonia и Native AOT. Native publish зависит от ОС: Windows собирается на Windows, Linux на Linux, macOS на macOS. SDK зафиксирован в [global.json](../../global.json); сервер и библиотеки имеют собственные target framework, перечисленные в [архитектуре](architecture.md).

| Платформа | Граница интеграции |
|---|---|
| Windows | Сквозной экранный слой, глобальные горячие клавиши, снимки рабочего стола, Win32-каталог и native optical effects |
| Linux X11/XWayland | XCB-каталог и дочерние регионы; compositor определяет доступность blur-behind |
| Linux native Wayland | Нет геометрии чужих окон; привязка масок отключена, экранные возможности ограничены |
| macOS | NSWindow/WindowServer-интеграция; выбор целого внешнего окна, без публичного каталога чужих NSView |

На Linux и macOS горячие клавиши работают при фокусе на окне приложения; в режиме обычного курсора экранный слой скрывается. В RDP/программном профиле оптические эффекты Windows могут использовать непрозрачный fallback. Реальная доступность compositor-функции не доказывается успешной сборкой.

Portable-поставка — вся publish-папка, включая модельный runtime, Giac и лицензии. Статически связанный renderer не делает остальные native-зависимости частью одного исполняемого файла. Установщики должны сохранять комплектность и соответствие платформы; отдельно установленный .NET для Native AOT не требуется.

Пакетные форматы, toolchain, системные зависимости и CI описаны в [сборке и упаковке](build-and-packaging.md). Ошибки загрузчика — в [диагностике](troubleshooting.md); требования к платформенной верификации — в [проверках](testing.md).
