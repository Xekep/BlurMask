# Маски: выбор цели и платформенные границы

Маска состоит из собственного окна, выбранной внешней цели и политики покрытия. Эти роли разделены, чтобы отрисовка эффекта не меняла цель, а отслеживание окна не вычисляло визуальный эффект.

| Компонент | Ответственность |
|---|---|
| `WindowFillPicker` | Поиск региона под текущим указателем и состояние предпросмотра |
| `IWindowCatalog` | Чтение внешних окон, геометрия, дочерние регионы, размещение маски |
| `MaskWindowAttachment` | Жизненный цикл привязки, обновления цели и видимость |
| `MaskAttachmentCoverage` | Защищённый прямоугольник после перемещения и изменения размера |
| `NovaPenWindow` | Рендеринг эффекта и ввод самого окна маски |

Контракты и реализации: [NativeWindowCatalog](../../src/NovaPen/NativeWindowCatalog.cs), [NativeMaskAttachment](../../src/NovaPen/NativeMaskAttachment.cs). `TrackedWindow` несёт нативный идентификатор, PID, физические границы и видимость; `ParentId` связывает дочерний регион с корнем для порядка окон.

Предпросмотр должен соответствовать текущей позиции указателя. Событие движения не гарантирует следующего события после остановки, поэтому таймерный кэш предыдущей цели может зависнуть. Подтверждение повторно проверяет цель перед созданием маски. Собственные окна процесса исключаются из выбора.

В Windows поиск заливки учитывает верхнее видимое чужое окно, в том числе без заголовка. Дочерний hit test выполняется нативно, а результат ограничивается клиентскими областями предков. Геометрия использует экранные пиксели; преобразование в единицы Avalonia выполняется на границе окна. Смешанный DPI и смена монитора требуют платформенной проверки.

X11 поддерживает дочерние окна; macOS без Accessibility-интеграции предоставляет целое окно. Нативный Wayland не раскрывает нужную геометрию внешних окон. Элемент веб-страницы или нарисованный виджет не обязательно имеет собственный HWND/XID.

Привязанная маска следует целевому порядку окон и не должна перекрывать чужой occluder. Изменение размера может защёлкнуть непрозрачное покрытие для защиты перераспределённого содержимого. Нативный выбор, порядок окон, сворачивание и DPI нельзя подтвердить только fake-каталогом; границы проверок перечислены в [testing](testing.md). Детали interop сохранены в [справочнике](reference/window-masks.md).
