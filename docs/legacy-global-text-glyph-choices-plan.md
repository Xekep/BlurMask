# Global glyph choices: scoped publication join

This checkpoint is static evidence and a runtime proposal. It does not publish
CHAR, WORD or TEXT source nodes, accept a document, or improve recognition quality.

The planned new owner takes the actual pre-NN global publication scope and its
own successful completion. It must retain the exact Document, global TOP, V140
metadata, refreshed pool, primary acoustic alphabet and pre-existing shared3E.
There are **zero old-file seams**: the existing internal scope.SharedState and
existing public raw-document selected-input copies provide the required access.
No configured/count1 owner can substitute for a global owner.

The actual WORD's complete reference list is copied before work. All ordinary
owners are refreshed before any alternative selection or UTF8 emission. Native
024F30 performs these as two distinct loops. The next loop uses actual13A830
selection and existing0213A0/021000 publication with explicitly supplied complete
allocator40 and selection4 storage. No inference is repeated.

13C717..13C733 extracts reference bits40..55 and explicitly sign extends bit15.
Its local signed marker is passed to274.V60. Success alone writes it back.
0213A0 removes empty emitted alternatives and decreases a marker only if the
removed retained position precedes it. A missing/out-of-range resulting marker
has no alternative fallback.

The HeaderE-filter provenance needs precision: 0213A0 checks **its third
argument byte8**, not knowledge99 directly. 024F30 forwards its third argument;
0283B0 passes its local138 object. Its byte8 lies in uStack130, initialized to
zero by the vector store028464. An original prior-result object at
originalTOP.field10.field10 can overwrite this through property12D0065 at
0285C6/0285E0. The library's fresh original bootstrap/selected-input route has
no imported/prior result object, so that branch is absent and filter is false.
Knowledge00C860's qword98 zeroing is a different producer and is insufficient
by itself to justify this wrapper flag. The planned API accepts no external
flag or prior-result/property input.

A separate NEW global document-position type retains the actual scope and
V140 metadata result. It recreates a value-preserving source-input map from
that exact Document.CopySelectedInputs(), uses actual group0 reference keys,
actual point ordinals and residual bytes, and calls the existing verified
05AFA0 ordinary projection. Its original root is the actual closed interval
from the first raw point through the final raw point. This is not a glyph box,
sampled stroke index, neural group or selected WORD span substituted for raw
source geometry. Native ordered append and closed/end-point modes remain
unchanged. Group offsets, C25 cached geometry, insertion/negative/protocol arcs,
multiple original collection intervals and prior objects remain explicit refusals.

Successful outputs retain only published UTF8 alternatives, original signed
reference/adjusted marker, source metadata and projected original ranges. Their
string identities belong to the same pre-NN3E. Scope closure invalidates access;
disposal of the choices facade does not dispose the borrowed shared pool.
Entry validation/cancellation precedes a one-use publication claim. Entered
failures retain ordered pool/string prefixes and poison this new owner; no
implicit rollback, retry or accepted transcription is synthesized.

Verification must cover actual procedural sources and, where stored tracks
are available, all nine recorded Russian tracks without feeding expected text
to recognition. Refusals are reported explicitly, rather than treating this
bounded one-WORD/ordinary route as full corpus coverage. Pool bytes, reference
order, all initial plus appended alternatives, marker/empty removal, Unicode
publication, packed original ranges, owner identity/lifetime and zero extra NN
are independently checked. Prepared marker/filter controls remain separately
identified. Russian text quality is evaluated after inference as a separate
diagnostic.

Run the static proof with:

```powershell
python tools/handwriting/audit_global_text_glyph_choices_plan.py REPORT.json
```

The script checks five complete pinned PE regions,25 exact instructions and
four existing static dependency closures. It reads SDK bytes and never loads
or executes them. Runtime and CHAR/WORD/TEXT publication are not implemented
by this checkpoint.
