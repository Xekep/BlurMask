# Rich first word to source720

`LegacyFirstResultSourceMaterializer` connects the actual rich-word output,
the shared glyph pool and the ordinary graph's source-range callback to the
existing `156950` source720 producer. It verifies the exact graph, cut
chronology, original source, pool and selected sampler owner before using any
glyph. Reading-order references are snapshotted once to avoid repeatedly
walking the linked word chain.

The selected alternative comes from the signed reference ordinal. The label,
confidence channels and integer cost come from the corresponding forty-byte
glyph record. Cropped ranges use actual graph source metadata; the increasing
child-to-parent map addresses the retained buffers submitted by `157C60`.
Normalized acoustic rectangles are not used as source membership.

A category owner loaded through249 preserves the actual serialized confidence
exponent, including the later clone copy. The Russian resource value is0.75.
A direct raw owner without249 uses the separately proved raw factory value1.
Main-source categories are rejected when the selected first source is expected.
Whole-stage point and range budgets are checked before geometry work.

The composition probe runs real first-network inference for35 groups, the
primary/B8 walk and rich word construction, then publishes twelve source720
snapshots: three glyphs, both exponent scopes and both contiguous and
discontinuous parent maps. An independent Python audit verifies range
projection, point bounds, scalar bytes, labels and missing alternatives.
Managed and Native AOT checks pass, including foreign ownership, mutation
isolation and cancellation.

The diagnostic text remains mixed-script `MИP`. This does not establish
Russian cursive accuracy. Full raw main-source orchestration, dictionary
winner selection and application integration are still separate stages.
