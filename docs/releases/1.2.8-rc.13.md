Промежуточная версия с дальнейшей интеграцией экспериментального движка.

- AI-перо теперь передаёт все полученные обычные словарные варианты через общий текстовый проход. Выбранный движком результат сохраняется; дополнительные варианты не подменяют его случайным выбором.
- Добавлены проверки целостности вариантов слова, исходных штрихов и отказа при незавершённой публикации текста.
- Три математические ветки используют общую подготовку геометрии вместо повторного вычисления одних и тех же признаков. Проверена пятая численная модель — признаки верхних направлений.

Проверены девять оригинальных записей через публичный путь AI-пера с обычным лимитом времени. Результаты совпали с предыдущим проверенным путём: приняты три результата «да», остальные отклонены текущим порогом. **Улучшение качества русского почерка в этой RC не подтверждено.**

Русский и английский слитный почерк, полный математический классификатор и перенос всего движка ещё не завершены. Новые математические компоненты библиотеки пока не составляют полный распознаватель формул. Экспериментальный движок включается в настройках; режим по умолчанию сохранён. Автоматический режим формул и вычисления после `=` сохраняют прежние возможности; Giac по умолчанию выключен.

Пакеты Windows, Debian, Arch Linux, Void Linux и macOS, независимые библиотеки и отдельный пакет моделей публикуются после успешных проверок сборки.
