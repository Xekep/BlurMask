# NovaPen 1.0.0

BlurMask теперь называется NovaPen. Этот выпуск начинает нумерацию заново; прежние данные пользователей и коды совместных полотен сохраняются.

- Рисование поверх рабочего стола и на отдельном полотне, совместная работа, фигуры, изображения и маски приватности.
- Нажатие колеса временно включает ластик также для линии, стрелки, прямоугольника и эллипса. После отпускания выбранный инструмент сохраняется.
- Исправлен обход глубоко вложенных дочерних окон при создании маски. Проверены 40 уровней настоящих Win32-окон и 29 проверок выбора и сопровождения; ошибка поиска больше не превращается в выбор более широкого родителя.
- Математические вычисления выполняет включённый в поставку Giac. Проверены точные интегралы, алгебра, пределы и производные; ∫₁¹⁰x²dx = 333. Это проверка вычисления готовой формулы, а не гарантия её распознавания.

Доступны установщик Windows и переносимый архив, пакеты Linux для Debian/Ubuntu, Arch и Void, а также архив macOS. Пакеты и Native AOT-сборки публикуются после прохождения проверок соответствующих платформ.

**Экспериментальный движок распознавания ещё не завершён.** Русский и английский слитный почерк, автоматическое определение текста/формул и применение повторного результата продолжают дорабатываться. Полный перенос движка и готовность русского языка не заявляются. На macOS остаётся несовпадение части хешей экспериментального Math2 с замороженным Windows-эталоном; повторяемость и сравнение свежего/повторного проходов внутри каждой системы проверены отдельно.

Заливка дочерних системных окон поддерживается на Windows и Linux/X11; в Wayland-сеансе через XWayland доступны только XWayland-окна. На macOS пока выбирается окно целиком. Элементы браузера или другого приложения без собственного системного окна отдельно не определяются.
