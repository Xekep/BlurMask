# NovaPen 1.0.0

Проект переименован в NovaPen; нумерация выпусков начинается с 1.0.0. Обновлены названия приложения, сайта, пакетов и установщиков для Windows, Linux и macOS.

Сайт pen.kiiko.ru уже показывает NovaPen. Из GitHub удалены 33 прежних выпуска и 33 тега. На сайте размещён новый снимок настоящего приложения, полученный в изолированном Linux/Xvfb.

Данные существующих пользователей и совместимые идентификаторы сетевого протокола сохранены. Архивные отчёты исследований остаются под исходными именами, чтобы сохранить происхождение и контрольные суммы.

Перенос распознавания текста и формул ещё не завершён. Исследовательские результаты не означают готовность всех путей движка или проверенную точность распознавания. Текущие ограничения описаны в [документации](../engineering/recognition.md). Математические вычисления выполняет отдельный Giac CLI.

Исправлена привязка масок: учитываются подходящие приложения без заголовка; рабочий стол, оболочка и пропускающие ввод многослойные оверлеи исключаются. Во время перетаскивания привязка обновляется с периодом 32 мс. Временное скрытие дочернего окна сохраняет его идентичность, чтобы привязка восстановилась после снятия маски с родительского окна.

Проверки текущего приложения: 14 проверок масок без интерфейса и 4 проверки реальных невидимых окон Windows пройдены; также пройдены все 7 проверок командной строки приложения, включая математический решатель.
