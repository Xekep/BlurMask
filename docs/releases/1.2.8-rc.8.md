Промежуточный выпуск с исправлениями экспериментального движка распознавания и расширенными проверками его независимой библиотеки.

- В экспериментальном русском распознавателе исправлен выбор акустического алгоритма 2B1, его калибровка и расчёт геометрических признаков. Переключатель нового движка остаётся выключенным по умолчанию.
- В независимой библиотеке добавлены проверенные компоненты английского MAIN-прохода: акустические признаки, объединение оценок, геометрия и стоимость переходов. Это отдельные этапы; полный английский словарный проход ещё не подключён к приложению.
- Добавлено ограниченное чтение структуры полных языковых ресурсов с проверками границ и принадлежности дочерних данных. Наличие ресурса само по себе не включает новый язык или готовый распознаватель.
- Расширены численные проверки Managed/Native AOT, отмены операций и работы с несколькими штрихами. Исправлена переносимость проверки акустических данных между ОС: вместо зависимости от контрольной суммы целого диагностического JSON выполняется независимая численная проверка.

Русский слитный почерк, автоматическое совместное распознавание русского и английского и перенос всего движка **ещё не завершены**. Этот RC не обещает улучшения точности: текущий фиксированный русский диагностический набор даёт 132 точных результата из 261. Это проверка отдельных слов, а не оценка произвольного почерка. Неподдерживаемый ввод и ошибки распознавания по-прежнему возможны.

Переключатель нового движка относится к тексту. Распознавание формул и включаемый отдельно Giac сохраняют прежний режим работы; этот выпуск не объявляет их полностью восстановленными.

Сборки выпуска: Windows Native AOT с установщиком, Linux с пакетами Debian/Arch/Void, macOS, отдельные пакеты библиотек и моделей. Готовые файлы публикуются после успешной сборки соответствующих пакетов.
