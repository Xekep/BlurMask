Промежуточный выпуск с экспериментальным распознаванием формул и исправлениями математических вычислений.

- При включённом экспериментальном движке режим **«Формулы»** использует восстановленный независимый путь Math2. Модель поставляется вместе с программой; устанавливать её отдельно не нужно. Для проверки выберите AI-перо, включите экспериментальный движок в настройках и выберите режим «Формулы».
- Исправлено вычисление пределов в записи, которую выдаёт распознаватель. Сохранены ограничения на неподдерживаемый и некорректный ввод.
- Исправлен порядок факториала и возведения в степень: `3!^2 = 36`, `2^3! = 64`. Определённый интеграл от 1 до 10 для `x² dx` проверен: результат `333`.
- Расчёт запускается при пустой правой части после знака `=`. Уже написанный ответ сохраняется. Для продвинутой символьной математики Giac включается отдельно в настройках; по умолчанию он выключен.
- Исправлено преобразование переполненных промежуточных значений в скалярном численном слое. Расширены проверки границ, прежних численных эталонов, отмены операций и поставки настоящей модели в Native AOT.

**Что ещё не готово:** русский слитный почерк, полный английский словарный проход и автоматический выбор текста/формул нового движка. Новый Math2 подключён только к явному режиму «Формулы»; его оценка не выдаётся за вероятность правильного распознавания. Полный перенос движка не завершён.

Этот RC не обещает улучшения русского почерка: повторный небольшой набор из девяти записей даёт 4 точных слова из 9. Набор слишком мал для оценки произвольного почерка. Два сгенерированных образца формул успешно прошли путь распознавания и расчёта, но не доказывают точность на любых рукописных выражениях.

Доступны сборки Windows Native AOT с установщиком, Linux с пакетами Debian/Arch/Void, macOS для архитектуры сборочного сервера, отдельные пакеты библиотек и моделей. Файлы прикрепляются автоматически после успешных сборок выпуска.
