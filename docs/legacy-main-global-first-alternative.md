# Actual global first alternative snapshot

`LegacyFreshMainGlobalFirstAlternativeSnapshot` captures the completed global
glyph execution session's first plain279 alternative. It requires the exact
terminal, successful callback tokens in chronological order and unchanged
published linked WORD list. Each token must retain the same execution session,
association session and glyph pool. Foreign terminals, missing/repeated/reversed
tokens, unfinished sessions and invalid result-query leases are refused.

The snapshot retains the actual global materialization and selected final88-byte
beam row. A prepublication terminal ordinal is not substituted for a compact
record index. Source-node count comes from that same global pass. Fresh reference
cost and the08/10/14 score channels use the existing numerical result kernels;
the first mass is not an acceptance probability.

The caller supplies all400 bytes of the first ten-row alternative allocation.
Only its first40-byte row is constructed and scored. The remaining360 bytes
retain their supplied allocator residue. Native pointer positions are portable
zero placeholders, with the real WORD head and beam owner retained as typed
references. No fake old single-source result object is constructed.

`LegacyMainGlobalFirstAlternative.Probe` executes eight raw global inputs,
completes their sixteen actual glyph callbacks and captures64 allocation variants
per owner:512 snapshots and120 ownership/chronology/cancellation controls.
The independent Python oracle checks614,400 complete constructor/scored/normalized
bytes and unchanged selected-row fields. Managed and Windows Native AOT captures
match exactly. Snapshots do not change the live glyph pool, WORD head or number
of acoustic-network evaluations. The included coordinates are diagnostic
fixtures, not a handwriting-accuracy benchmark.

```
LegacyMainGlobalFirstAlternative.Probe AK engine separation case publication line30 line50 capture LK
python tools/LegacyMainGlobalFirstAlternative.Probe/audit_output.py capture
python tools/handwriting/audit_main_global_first_alternative.py static-report.json
```

The static auditor composes the pinned actual global TOP ownership,
word-publication callback, native alternative construction and numerical score
audits. It never loads vendor code.

This is a postcallback snapshot. It does not reproduce the complete native
allocation/failure ordering or execute quote normalization, glyph rewriting,
duplicate exclusion, multiple alternatives or final document acceptance.
