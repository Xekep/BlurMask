# Original Math source and FIELD library application

`Math2Mode0OriginalApplication.Prepare(actualField, actualOutgoing)` consumes the
genuine completed outgoing Math owner against the SAME retained original field
source. It preserves historical constructor snapshots, mutates that source's
actual private original registry/C22/Next, and publishes a new active original
PAGE overlay after successful source execution. This is a bounded library
application: native CBB, cache revisions, original BE2/Base70 history, listeners,
automatic combined rollback and the application recognizer switch remain absent.

Only two old files change: the completed outgoing trusted application accessor
and the original field's gated accessor/mutation delegates. The outgoing accessor
validates live authority through the existing publisher before entering the
same-field mutation view. It compares the exact immutable original Ink identity
before calling another source accessor. Entry to that accessor requires this
same source gate ALREADY held plus the genuine outgoing gate held and its exact
completed payload objects alive. Field → publisher → outgoing → application is
the lock order; no receipt validation is taken under those locks. Actual source
registration also requires reference membership in the outgoing command list.
An equal detached command object cannot authorize a registration.

Pristine original INPUT-only/Next1 is checked once before the application claim.
Subsequent live operations use the exact claimed application, immutable historical
snapshot and its active original registry. Selected INPUT/Next1 and third registry
stay unchanged, so the original publisher's existing guards remain strict.
The old `Math2Mode0OriginalMathFieldSource.CopySnapshot()` keeps its historical
nodes/ranges/Next and old captures; the new application's `ActiveRegistry`,
`ActiveNext` and `ActivePage` explicitly report current original state.

## Whole-field scratch precedes original source mutation

The complete outgoing/source/journal/historical/scratch/live-copy logical envelope
is checked before copies or claim: aggregate65536-node budget, payload depth240
(leaving space under the original PAGE),32MiB name/value bytes and64MiB retained
envelope including the outgoing owner. Actual counts/values/ranges supply it.
These are bounded managed storage/work envelopes, not process RSS guarantees.
Preentry cancellation and exact-budget refusal do not consume the original.

Prepare imports the entire historical PAGE and id/INPUT/layout/namespace graph,
retaining actual original name-owner tokens. It scratch-clones the WHOLE kind3
field, copies the genuine outgoing mathResult, maps the empty field-relative
parent and inserts at derived ordinal1 after INPUT. Typed tag/range compatibility
is checked against the actual incoming source commands and original INPUT.
Prepared status is set only after the scratch operation passes. Scratch and
active PAGE remain separate graphs, with distinct original-node and outgoing-
payload provenance. Node/child indexes bound traversal; no native clone ID or
pointer is fabricated.

## Actual original source mutation and generated inverse history

`RunSource()` first clones each detached command selection into a genuine private
C22 owned by the retained original Ink. A separate original-target history C22
clone is prepared, then the same actual command ID/name/category102 is registered
in the original private dictionary. Equal-range C22s intern against existing
original entries, including the original INPUT for a full-domain MATH_NODE.
Actual returned IDs are checked; a nonidentity registration is outside this
first branch. Requested→actual pairs are derived from the successful entries
and validated again before DOM application.

Generated original inverse records retain the actual command, separate history
C22 and actual original registration identity. They are not relabelled incoming
C4D commands. Both the native before90 allocation/refusal and after98 finalization
refusal are represented as separately named logical diagnostics: clear the
generated frame, latch `JournalComplete=false`, and continue the actual original
registration. `SourceExecutionSucceeded` may therefore be true with incomplete
history. Such an owner cannot enter the live DOM phase or perform a misleading
partial source inverse. The category102 CB7 event0 reduction is recorded and
discarded before original tag traversal; no geometry is fabricated.

Contiguous explicit IDs advance actual original Next. The real trailing
operation7 therefore takes its skip branch. Before DOM entry, `RollbackSource()`
walks generated records backwards and deletes only their exact new original
entries. It leaves Next monotonically advanced and original INPUT intact.
It does not restore initial Next1 or claim byte-exact native C51 cache state.
Entered source/inverse failure preserves completed registrations/deletions and
poisons further writes; no automatic rollback is invented.

## Original FIELD publication

`ApplyDom()` requires successful source execution, complete generated history,
live borrowed owners and the same active original registry identities. It marks
DOM entry BEFORE copying. Once this phase enters, source-only rollback is blocked,
even if a later clone/cancellation/postcheck fails. Deleting IDs while retaining
inserted tags would corrupt the graph; a genuine combined inverse remains future
work.

The actual outgoing payload is copied/re-interned into the original name owner
and inserted into the existing mathField after its INPUT. Every old PAGE/id/INPUT/
layout/attribute node remains present and ordered. Canonical token owner and
reference identity are checked from actual node tokens, not inferred from equal
strings. The final graph recursively resolves each present signed64/value-kind4
tag in the same active original registry and performs actual C21 containment
against the retained original INPUT selection. Naturally untagged containers are
allowed. Missing mandatory INPUT, malformed present tags and missing referenced
IDs are strict safe library refusals; they are not claimed equivalent to native
1156E0's absent-tag success or unsafe missing-ID dereference. A failed postcheck
preserves the already inserted result and source prefix. A separately named
library epoch advances only after successful publication; it is not native
field-state48 or cache98/A8.

Closing the field, receipt, publisher or outgoing owner revokes live operations.
Historical/active diagnostic snapshots remain readable and deep-copy mutable
arrays. Application disposal has one logical cleanup transition, disposes no
borrowed owner and performs no source inverse. Managed diagnostic trees and
journal objects remain retained for inspection/GC; this is not native allocator
free semantics. Source-backed NN outputs are not retained by this owner.

ownership/transport/application, **not** nontrivial formula recognition, Russian
handwriting, integral evaluation or complete engine recovery. Expected text is
