## Matching and ownership limits

The package also pins the complete029890 matching entry and024840/025670 callers.029890 checks the real cancellation callback and configured time limit, maintains actual matched-state caches, and enters additional matching helpers. Pinning this containing body does not close its transitive match/feature dependencies or make a prepared result tree an acceptable substitute.

Native allocation and callback failures can leave modified source/candidate prefixes. No atomic rollback, generic native edit ABI, concurrent native-reference behavior or full false-path cleanup equivalence is claimed. A future owning runtime needs complete work preflight, cancellation, exact request/resource identities and explicit poison/lifetime policy. It cannot quietly skip unsupported active operators or select an easier candidate by the expected answer.
