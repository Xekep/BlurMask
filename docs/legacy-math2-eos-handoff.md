# Prepared Math2 observable-prefix and EOS handoff

`LegacyMath2ObservableTokens` binds only the fingerprinted bundled raw Math2
resource. It retains the actual299-label source alphabet, derives the finite
single-scalar interval and special labels, and implements the03EFF0 unsigned
predicate. This is an observable-prefix test, not a grammar or confidence gate.
The bundled absent-special profile establishes native AL+12 asFFFF; arbitrary
wire-to-object mappings or token-rendering aliases are not generalized. Other
resource fingerprints are explicitly refused. It does not treat the297-class
decoder vocabulary as the299-label source alphabet.

`LegacyPreparedMathEosHandoff` connects the owned unrestricted candidate result
to a positive prepared numerical stage. It copies the full sorted48-byte
records into a distinct retained lifecycle, preserves its actual source owner,
and takes explicit same-sized per-beam prefix sidecars. It is not the complete
native decoder or a public recognizer.

The stage preserves the native order:

1. For delta less than1000, calculate the threshold with one float32 best+delta
   addition and mask ordered candidate costs at least that threshold from rank1.
   Negative delta is active; unordered delta skips this branch.
2. Scan all2*width records for non-FMAX EOS class1. Only ranks below width with
   any observable prefix token collect the no-constraint completed numeric score.
   Structural tokens can coexist with observable tokens in that prefix.
3. Mark every encountered non-FMAX EOS record, even if it could not collect a
   completion; re-sort the entire capacity with035F70.
4. Start the active count at1, then inspect ranks1 through width-1 until FMAX.
   An all-FMAX width-one continuation therefore still has count1.

The existing completed-score kernel receives cost including EOS and prefix
length excluding EOS. Only finite nonnegative selected candidate costs and
bounded valid decoder prefixes are supported here. No037430 full168-byte
construction, allocation failure lifetime, max-position fallback, configured
constraint exponent, accepted expression or tensor/cache reindexing is
manufactured. Each result exposes explicit prepared snapshots and numeric
scores, never app replacement text.

The combined math probe verifies the predicate over all65536 IDs from an
independent raw-AL oracle. Another980 prepared joins cover five widths,
negative/zero/positive/disabled/unordered/infinite delta and seven prefix
patterns. They produce1056 independently checked numeric completions, including
264 mixed-prefix cases distinguishing ANY from ALL. Full pruning, EOS and
re-sort record bytes are compared, including the width-one equal-FMAX reversal
where a masked runner-up becomes the continuation. Managed and Native AOT
captures match in full. These are algorithm controls, not handwriting accuracy.
