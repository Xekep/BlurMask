# FIRST276 partial numerical regression

Runs the actual original-input route with the original 14 recipes. Twelve cases
must yield all 201 known hidden values, 257 post-exponential values and C0 exactly;
two preserve their original directional source-point refusals. Expectations use
the resource weights and native integer lookup tables, and independently replay
the prior sampler/segment recordings through the input14 oracle. No new C# output
feeds the expected computation. Corruption and all-refusal captures are rejected.

This tests a partial numerical prefix. Normalization, alphabet/class mapping,
shortlists, recognition quality and NativeAOT are not covered. Unknown padding
and slot zero are neither exported nor treated as zero. All twelve actual C0
values happen to be zero; positive-offset behavior has only synthetic coverage.
