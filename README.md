# NovaPen

Настольное приложение для рисования поверх экрана, совместной работы на отдельной доске и маскировки личных данных во время записи. Перо, фигуры, текст, выделение и история изменений доступны с плавающей панели.

**[Скачать](https://github.com/Xekep/NovaPen/releases/latest)** · [Изменения 1.0.0](docs/releases/1.0.0.md) · [Документация проекта](docs/engineering/README.md) · [Материалы для агентов](docs/agents/README.md)

## Возможности

- Рисование поверх приложений, временные пометки, выделение, перемещение, масштабирование и поворот объектов.
- Независимая доска с локальным сохранением, изображениями, экспортом в PNG и совместным рисованием по приглашению.
- Маски приватности с несколькими эффектами, привязкой к окну и заливкой выбранного нативного региона. Сплошная заливка закрывает изображение полностью; оптические эффекты сохраняют часть контекста.
- Экспериментальное локальное распознавание текста и формул. Все математические вычисления выполняет отдельный процесс Giac; переключатель включён в новых настройках, сохранённый выбор сохраняется.

Windows поддерживает глобальные сочетания, скриншоты и сквозной экранный слой. Linux и macOS имеют [платформенные ограничения](docs/engineering/platforms.md). Экранные пометки остаются локальными; сервер получает только доску с включённой совместной работой. Распознавание и вычисления не требуют облачного API.

Проверки текущей сборки: 14 проверок масок без интерфейса, 4 проверки реальных невидимых окон Windows и все 7 проверок командной строки приложения пройдены. Они проверяют поведение приложения и не заменяют оценку качества распознавания.

## Устройство проекта

Приложение написано на C# и Avalonia, поставляется через Native AOT. Библиотеки распознавания и решатель отделены от UI; ASP.NET Core-сервер хранит общие доски в PostgreSQL. [Архитектура](docs/engineering/architecture.md) описывает зависимости, владельцев состояния, интерфейсы и границы ответственности.

Инженеру, который знакомится с кодом: [карта документации](docs/engineering/README.md), [сборка и упаковка](docs/engineering/build-and-packaging.md), [проверки](docs/engineering/testing.md). Процедуры переноса движка, происхождение данных и исторические доказательства собраны отдельно в [docs/agents](docs/agents/README.md).

Русская рукопись и полный английский MAIN-декодер ещё не готовы. Пройденные проверки отдельных операций не являются оценкой качества распознавания; актуальные границы перечислены в [состоянии переноса](docs/agents/research/recognition-progress-20261029-novapen.md).
